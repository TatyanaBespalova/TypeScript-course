объекты - еще один тип данных в TS
Массивы, фуекции  - объекты
объекты определяют дату. Имеют свойства и функции (методы)
методы позволяют оюъектам действовать : object.doSomething()
методов в объекте можно быть много , или столько, сколько нужно
методы могут ссылаться на объект через this
значение this определяется во время исполнения кода
стрелочные функции  - особенны, у них нет this
когда внутри стрелочной функции обращаются к this  - значение берется от родителя
Когда мы пишем код  - нет необходимости писать строчку за строчкой
Мы можем использовать функции для объединения кода по функционалу и объекты для опредения даты
мы должны указывать типы данных для объектов
тип данных может указываться как интерфейс и как тип
