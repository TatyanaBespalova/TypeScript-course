## 1. Что такое массив и зачем он нужен

Массив хранит несколько значений в одной переменной. Лектор отметил, что массивы используются очень часто, особенно когда данные приходят извне и их нужно обработать.

Пример из автоматизации, приведённый на лекции: на странице есть несколько кнопок, и нужно проверить, что все они зелёные. Полученный набор кнопок можно представить как массив, а затем проверить его элементы.

### Типизированные массивы

Тип элементов записывается перед квадратными скобками:

```ts
let words: string[] = ["hello", "world"];
let numbers: number[] = [1, 2, 3];
let flags: boolean[] = [true, false];
```

- `string[]` — массив строк;
- `number[]` — массив чисел;
- `boolean[]` — массив логических значений.

### Вложенный массив

Если каждый элемент внешнего массива тоже является массивом, получается вложенный, или двухуровневый, массив.

```ts
const array: number[][] = [
  [0, 1, 2, 3, 45],
  [10, 11, 12, 13, 14],
  [20, 21, 22, 23, 24],
  [30, 31, 32, 33, 34],
];
```

Тип `number[][]` означает: внешний массив содержит внутренние массивы, а внутри них находятся числа.

## 2. Обращение к элементам по индексу

Индекс указывается в квадратных скобках после имени массива. Отсчёт начинается с нуля.

### Простой пример из лекции

```ts
const numbers: number[] = [10, 20, 30];

console.log(numbers[0]); // 10
```

`numbers[0]` — первый элемент, а не «нулевой» по порядку.

### Пример среднего уровня из лекции: вложенный массив

```ts
const array: number[][] = [
  [0, 1, 2],
  [10, 11, 12],
];

console.log(array[0]); // [0, 1, 2]
```

`array[0]` возвращает первый элемент внешнего массива. Поскольку элементы внешнего массива сами являются массивами, результатом будет внутренний массив.

Чтобы получить одно число из внутреннего массива, нужны два индекса:

```ts
console.log(array[0][1]); // 1
```

### Дополнения от AI

Первый индекс выбирает строку (внутренний массив), второй — элемент внутри неё: `array[0][1]` означает «первый внутренний массив, второй элемент». Именно такого отдельного объяснения двух индексов на лекции не было; основное внимание было на `array[0]`.

## 3. Преобразование массива в строку

На лекции сравнивались два способа: `toString()` и `join()`.

### Метод `toString()`

`toString()` преобразует массив в строку. В показанном примере элементы разделяются запятыми.

```ts
const numbers: number[] = [1, 2, 3];

console.log(numbers.toString()); // "1,2,3"
```

Лектор отметил, что `toString()` не позволяет выбрать другой разделитель.

### Метод `join()`

`join()` соединяет элементы массива и возвращает строку. Разделитель передаётся в круглых скобках.

#### Простой пример из лекции

```ts
const numbers: number[] = [1, 2, 3];

console.log(numbers.join(" ")); // "1 2 3"
console.log(numbers.join("+")); // "1+2+3"
```

Если разделитель не передан, по умолчанию используется запятая:

```ts
console.log(numbers.join()); // "1,2,3"
```

На курсе лектор рекомендовал явно писать разделитель, даже когда нужна запятая:

```ts
console.log(numbers.join(",")); // "1,2,3"
```

Так при чтении кода сразу видно, каким будет результат.

#### Пример среднего уровня из лекции: внешний массив

В Codewars разбиралась задача **CSV representation of array**. Требовалось превратить двухуровневый массив в одну строку: элементы каждого внутреннего массива разделяются запятыми, а внутренние массивы — переносами строки.

```ts
export function toCsvText(array: number[][]): string {
  return array.join("\n");
}
```

Для массива

```ts
[
  [0, 1, 2, 3, 45],
  [10, 11, 12, 13, 14],
  [20, 21, 22, 23, 24],
  [30, 31, 32, 33, 34],
]
```

результат имеет вид:

```text
0,1,2,3,45
10,11,12,13,14
20,21,22,23,24
30,31,32,33,34
```

Логика, сформулированная на лекции:

1. `join("\n")` применяется к внешнему массиву.
2. Каждый внутренний массив преобразуется в строку с запятыми.
3. Полученные строки соединяются символом переноса строки `\n`.

### `+` при работе со строками

Если оператор `+` применяется к строкам, происходит конкатенация — соединение строк.

```ts
const first: string = "Hello";
const second: string = "World";

console.log(first + second); // "HelloWorld"
```

Первоначально задачу собирались решать вручную:

```ts
array[0].toString() + "\n" +
array[1].toString() + "\n" +
array[2].toString() + "\n" +
array[3].toString();
```

Затем было найдено более короткое решение `array.join("\n")`.

### `\n` и `\\n`

- `"\n"` — специальный символ переноса строки.
- `"\\n"` — текст из обратного слеша и буквы `n`; перенос не выполняется.

```ts
console.log("one\ntwo");
// one
// two

console.log("one\\ntwo");
// one\ntwo
```

> **В лекции изложено невнятно:** обсуждение того, является ли `\n` частью видимой строки Codewars или реальным переносом строки, несколько раз меняло направление. В итоге рабочее решение использовало `array.join("\n")`, то есть настоящий перенос строки.

### Дополнения от AI

В исходном коде строка хранит специальный символ `\n`. Codewars может показывать ожидаемое значение в техническом представлении как `"...\n..."`, но при выводе через `console.log()` этот символ создаёт новую строку. Чтобы вывести именно два видимых символа `\` и `n`, нужен `"\\n"`.

> **В лекции изложено невнятно:** лектор объяснил, что `join()` внешнего массива также преобразует вложенные массивы, но механизм этого преобразования был описан очень общо.

### Дополнения от AI

В этом конкретном примере каждый внутренний массив при преобразовании в строку даёт значения через запятую. Разделитель `"\n"` относится только к элементам внешнего массива. Поэтому решение работает для требуемого формата без пробелов после запятых. Сам лектор отдельно предупредил: если бы требовалось `", "`, это решение уже не дало бы нужный формат внутренних массивов.

## 4. Преобразование строки в массив: `split()`

`split()` — строковый метод. Он разбивает строку по указанному разделителю и возвращает массив строк.

### Простой пример из лекции: разделение по пробелу

```ts
const text: string = "Hello World";

console.log(text.split(" ")); // ["Hello", "World"]
```

Алгоритм был объяснён так:

1. Метод идёт по строке слева направо.
2. Находит указанный разделитель — в примере пробел.
3. Текст до разделителя становится элементом массива.
4. Сам разделитель в результат не попадает.
5. Поиск продолжается после разделителя.

### Разделение на отдельные символы

Пустая строка как разделитель разбивает текст на символы:

```ts
const text: string = "Hello";

console.log(text.split(""));
// ["H", "e", "l", "l", "o"]
```

Пробел внутри исходной строки в этом случае тоже станет отдельным элементом массива.

```ts
const text: string = "Hi all";

console.log(text.split(""));
// ["H", "i", " ", "a", "l", "l"]
```

### Пример среднего уровня из лекции: задача Codewars

Задача **Convert a string to an array** требовала получить массив слов.

```ts
export function stringToArray(s: string): string[] {
  return s.split(" ");
}
```

Примеры тестов, показанные в записи:

```ts
stringToArray("Robin Singh");
// ["Robin", "Singh"]

stringToArray("I love arrays they are my favorite");
// ["I", "love", "arrays", "they", "are", "my", "favorite"]
```

### Разделение по другому символу

Лектор показал принцип на строке, содержащей несколько букв `d`: если передать `"d"` в `split()`, строка будет разрезана в каждой позиции, где находится `d`. Сама буква-разделитель в результат не войдёт.

> **В лекции изложено невнятно:** при обсуждении `split()` без аргумента прозвучало, что JavaScript возвращает исходную строку единственным элементом массива, а TypeScript якобы выдаёт ошибку. В записи это утверждение не было подтверждено рабочим примером.

### Дополнения от AI

В обычном TypeScript вызов `text.split()` допустим и возвращает массив с исходной строкой как единственным элементом: `[text]`. Не путайте три варианта:

```ts
text.split(" "); // массив слов, если слова разделены одиночными пробелами
text.split("");  // массив отдельных символов
text.split();    // массив из одного элемента — всей исходной строки
```

## 5. Цепочка методов: `replaceAll()` и `split()`

На лекции возникла дополнительная задача: разбить строку на отдельные символы, но не сохранять пробелы.

Сначала все пробелы заменяются на пустую строку, затем результат разбивается на символы:

```ts
const text: string = "I love arrays they are my favorite";

console.log(text.replaceAll(" ", "").split(""));
```

### Как читать цепочку

```ts
text.replaceAll(" ", "").split("")
```

1. `replaceAll(" ", "")` находит все пробелы и заменяет их на «ничего».
2. Возвращается новая строка без пробелов.
3. К этой строке сразу применяется `.split("")`.
4. Получается массив отдельных символов без пробелов.

### Простой вариант из лекции

```ts
const text: string = "a b";

console.log(text.replaceAll(" ", "")); // "ab"
```

### Пример среднего уровня из лекции

```ts
const text: string = "a b";

console.log(text.replaceAll(" ", "").split(""));
// ["a", "b"]
```

Лектор отметил, что те же операции можно было бы записать в несколько строк, если так понятнее новичку.

### Дополнения от AI

Эквивалентная пошаговая запись помогает увидеть промежуточный результат:

```ts
const withoutSpaces: string = text.replaceAll(" ", "");
const characters: string[] = withoutSpaces.split("");
```

Это тот же алгоритм, который показан на лекции; изменена только форма записи для чтения.

## 8. Преобразование строкового числа в число

Для преобразования строки `"1"` в число `1` на лекции использовался `Number()`.

### Простой пример из лекции

```ts
const value: string = "1";
const numericValue: number = Number(value);

console.log(numericValue);         // 1
console.log(typeof numericValue);  // "number"
```

`typeof` использовался, чтобы проверить тип полученного значения.

### Пример среднего уровня из лекции: значение из массива

```ts
const oldArray: string[] = ["1", "2", "3"];
const element1: number = Number(oldArray[0]);

console.log(element1);        // 1
console.log(typeof element1); // "number"
```

Также лектор назвал `parseInt()` как ещё один способ, но разницу между `Number()` и `parseInt()` не объяснил. Сравнить их было задано как домашнее задание.

> **В лекции изложено неполно:** не объяснено, в каких случаях следует выбирать `Number()`, а в каких `parseInt()`.

### Дополнения от AI

Здесь я намеренно не добавляю сравнение этих двух способов: лектор выделил его как отдельное домашнее исследование, а не как изученный материал данной лекции.

## 9. Создание нового массива и добавление элементов: `push()`

Пустой массив необходимо не только объявить, но и инициализировать:

```ts
let newArray: number[] = [];
```

Метод `push()` добавляет значение в конец массива. Он вызывается у конкретного массива:

```ts
newArray.push(1);
```

Нельзя писать только `push(1)`, потому что `push` — метод массива и нужно указать, с каким массивом он работает.

### Простой пример из лекции

```ts
let numbers: number[] = [];

numbers.push(1);
console.log(numbers); // [1]
```

### Пример среднего уровня из лекции: новый числовой массив

На занятии строки преобразовывались по одному, после чего числа добавлялись в новый массив:

```ts
let oldArray: string[] = ["1", "2", "3", "4", "5"];
let newArray: number[] = [];

let element1: number = Number(oldArray[0]);
newArray.push(element1);

let element2: number = Number(oldArray[1]);
newArray.push(element2);

let element3: number = Number(oldArray[2]);
newArray.push(element3);

console.log(newArray); // [1, 2, 3]
```

Лектор пояснил: на текущем уровне те же действия пришлось бы повторить для каждого элемента. Способ обработать сразу любое количество элементов будет изучаться позже вместе с циклами.

> **В лекции изложено невнятно:** прозвучало, что без `=[]` создаётся «undefined-массив» и что в JavaScript добавление через `push()` при этом работало бы нормально.

### Дополнения от AI

Запись `let newArray: number[];` объявляет переменную, но пока не создаёт массив. Поэтому вызывать `newArray.push(...)` ещё нельзя. Запись `let newArray: number[] = [];` создаёт реальный пустой массив. В обычном JavaScript вызов `push()` у переменной со значением `undefined` также завершился бы ошибкой во время выполнения; TypeScript полезен тем, что предупреждает о проблеме заранее.

## 10. Суммирование элементов массива

После преобразования строк в числа элементы складывались вручную по индексам:

```ts
const newArray: number[] = [1, 2, 3];

const sum: number = newArray[0] + newArray[1] + newArray[2];
console.log(sum); // 6
```

### Важно: сложение или конкатенация

Лектор обратил внимание: оператор `+` складывает числа, но при наличии строки может соединять значения как текст.

#### Простой пример из лекции

```ts
const result: number = 1 + 2 + 3;
console.log(result); // 6
```

#### Пример среднего уровня из лекции

```ts
const source: string[] = ["1", "2", "3"];

const n1: number = Number(source[0]);
const n2: number = Number(source[1]);
const n3: number = Number(source[2]);

const sum: number = n1 + n2 + n3;
console.log(sum); // 6
```

Перед сложением нужно убедиться, что каждое значение имеет тип `number`.

### Что сказано о более коротком решении

В конце обсуждались возможные готовые способы суммирования. В VS Code искали метод `Math.sumPrecise`, но он не появился и не был использован. Затем участники назвали `reduce()`; лектор подтвердил, что через `reduce()` задачу можно решить, но этот метод ещё не изучался.

> **В лекции изложено невнятно:** обсуждение `Math.sumPrecise` закончилось без установленного результата. Рабочего примера этого метода в лекции нет.

### Дополнения от AI

Для заданий по материалу этой лекции опирайтесь на реально выполненный вариант: преобразование элементов в числа и ручное сложение по индексам. `reduce()` только назван как будущий, более общий способ; его синтаксис и работа здесь не объяснялись.

## 11. Читаемость, форматирование и подсказки редактора

Лектор несколько раз подчёркивал:

- ставить пробелы и разделять код на логические блоки;
- выбирать запись, смысл которой сразу виден;
- на начальном этапе печатать код самостоятельно;
- временно не полагаться на AI-подсказки и автодополнение, если они мешают понять, какая часть написана самостоятельно;
- на курсе использовать двойные кавычки, хотя Codewars может использовать одинарные;
- конкретный стиль кавычек обычно зависит от правил проекта или компании.

### Простой пример читаемой записи

## 12. Краткая памятка

| Задача | Запись из лекции | Результат |
| --- | --- | --- |
| Тип массива строк | `string[]` | массив строк |
| Тип массива чисел | `number[]` | массив чисел |
| Двухуровневый массив чисел | `number[][]` | массив массивов чисел |
| Первый элемент | `array[0]` | значение с индексом `0` |
| Массив в строку | `array.toString()` | строка с запятыми |
| Массив в строку с выбранным разделителем | `array.join("-")` | элементы через `-` |
| Строка в массив слов | `text.split(" ")` | слова без пробелов-разделителей |
| Строка в массив символов | `text.split("")` | отдельные символы |
| Удалить все пробелы | `text.replaceAll(" ", "")` | строка без пробелов |
| Строковое число в число | `Number("1")` | число `1` |
| Проверить тип | `typeof value` | строка с названием типа |
| Создать пустой числовой массив | `let values: number[] = [];` | пустой массив |
| Добавить элемент в конец | `values.push(1)` | массив с новым элементом |
| Перенос строки | `"\n"` | новая строка |
| Видимые символы `\n` | `"\\n"` | обратный слеш и `n` |

# Ответы на вопросы

1. `string[]`.
2. С нуля.
3. Первый внутренний массив.
4. `toString()` использует запятые, а `join()` позволяет явно задать разделитель.
5. Запятую.
6. Преобразует внутренние массивы в строки с запятыми и соединяет их переносами строк.
7. `"\n"` создаёт перенос строки; `"\\n"` выводит видимые символы `\` и `n`.
8. Массив частей строки, разделённых пробелами; сами пробелы-разделители не входят в результат.
9. Массив отдельных символов, включая пробелы, если они есть в исходной строке.
10. `text.replaceAll(" ", "").split("")`.
11. Функция должна вернуть массив, каждый элемент которого является строкой.
12. `any` отключает значительную часть проверки типов и противоречит основной цели использования TypeScript.
13. `Number("3")`.
14. Чтобы узнать тип значения во время выполнения; в лекции проверялось, что результат преобразования имеет тип `number`.
15. `=[]` создаёт пустой массив, в который уже можно добавлять элементы. Одного объявления переменной недостаточно.
16. `numbers.push(value)`.
17. Чтобы оператор `+` выполнял числовое сложение, а не конкатенацию строк.
18. `reduce()`.
19. `TEST` запускает видимые примеры, а `ATTEMPT` — более полный набор тестов, включая скрытые.
20. Разобраться, чем отличаются `Number()` и `parseInt()` и когда применять каждый способ.
