## 1. Повторение: три части цикла `for`

В начале записи продолжается работа с циклом `for`. На экране показана его общая форма:

```ts
for (инициализация; условие; изменение) {
  // тело цикла
}
```

Лектор по очереди убирает отдельные части цикла и показывает варианты вроде:

```ts
let i = 0;

for (;;) {
}
```

и:

```ts
for (let i = 0; ; i++) {
}
```

### Простой пример из лекции

```ts
for (let i = 0; i < 5; i++) {
}
```

### Пример среднего уровня из лекции

```ts
let i = 0;

for (;;) {
  // все три части заголовка пропущены
}
```

> **В лекции изложено неполно:** на показанном фрагменте пустые части цикла рассматриваются как синтаксические варианты, но законченный безопасный пример с условием выхода не демонстрируется.

### Дополнения от AI

`for (;;)` создаёт цикл без условия завершения. Для учебного безопасного примера нужен явный выход:

```ts
let i = 0;

for (;;) {
  if (i === 3) break;
  console.log(i);
  i++;
}
```

Этот пример добавлен AI и в записи не показывался.

## 2. Перебор массива: фиксированная граница и `arr.length`

Лектор создаёт массив и перебирает его циклом:

```ts
let arr: number[] = [1, 2, 3];
let str: string = "";

for (let i = 0; i < arr.length; i++) {
  str += arr[i] + ", ";
}

console.log(str);
```

В Output показан результат:

```text
1, 2, 3,
```

Перед использованием `arr.length` на экране присутствует вариант с фиксированной границей:

```ts
for (let i = 0; i < 5; i++) {
  str += arr[i];
}
```

### Простой пример из лекции

```ts
let arr: number[] = [1, 2, 3];

for (let i = 0; i < arr.length; i++) {
  console.log(arr[i]);
}
```

### Пример среднего уровня из лекции

```ts
let arr: number[] = [1, 2, 3];
let str = "";

for (let i = 0; i < arr.length; i++) {
  str += arr[i] + ", ";
}

console.log(str);
```

### Дополнения от AI

Для массива из трёх элементов условие `i < 5` приводит к попыткам прочитать индексы `3` и `4`, которых нет. Вариант `i < arr.length` автоматически использует реальную длину массива и остаётся корректным при изменении количества элементов.

## 3. Массив, содержащий числа и вложенный массив

В записи показан тип:

```ts
let arr: (number | number[])[] = [1, 2, 3, [10, 11, 12]];
```

Затем лектор начинает строить вложенный цикл и обращаться к элементу так:

```ts
arr[i][j];
```

Редактор подчёркивает это выражение как проблему. Причина прямо на экране не оформляется в законченный пример.

### Простой пример из лекции

```ts
let arr: (number | number[])[] = [1, 2, 3, [10, 11, 12]];
```

### Пример среднего уровня из лекции

```ts
for (let i = 0; i < arr.length; i++) {
  for (let j = 0; j < 5; j++) {
    arr[i][j];
  }
}
```

> **В лекции изложено невнятно:** показанный вложенный цикл остаётся с ошибкой и затем очищается. Готовое решение в этой части не показывается.

### Дополнения от AI

Элемент `arr[i]` имеет тип `number | number[]`. Индекс `[j]` можно применять только после проверки, что текущий элемент действительно является массивом:

```ts
for (let i = 0; i < arr.length; i++) {
  const item = arr[i];

  if (Array.isArray(item)) {
    for (let j = 0; j < item.length; j++) {
      console.log(item[j]);
    }
  } else {
    console.log(item);
  }
}
```

Это решение предложено AI; в лекции оно не было доведено до такого вида.

## 4. Что такое функция и зачем она нужна

В файле лекции записано:

- функция — ещё один тип данных в TypeScript;
- это код, написанный отдельно от остального кода и выполняющий одну определённую задачу;
- функции нужны для многократного использования кода;
- функция помогает не повторять одинаковый код;
- функции помогают создавать легко читаемый, чистый код.

Для демонстрации повторения кода сначала выводятся одинаковые заголовки перед несколькими вычислениями:

```ts
const a: number = 5;
const b: number = 10;

console.log("\nResult of calculations: ");
console.log("----------------------");
console.log(a + b);

console.log("\nResult of calculations: ");
console.log("----------------------");
console.log(a - b);

console.log("\nResult of calculations: ");
console.log("----------------------");
console.log(a * b);
```

В Output видны результаты `15`, `-5` и `50`.

### Простой пример из лекции

```ts
console.log(a + b);
```

### Пример среднего уровня из лекции

```ts
console.log("\nResult of calculations: ");
console.log("----------------------");
console.log(a + b);
```

### Дополнения от AI

Повторяющиеся две строки заголовка становятся кандидатом на отдельную функцию. Именно этот пример подводит к следующему разделу.

## 5. Объявление функции

Лектор показывает шаблон объявления:

```ts
function ИмяФункции(): тип {
  // тело функции
  return результат;
}
```

В комментариях к шаблону указано:

- `function` — зарезервированное слово;
- имя функции должно понятно описывать, что делает функция;
- имя может содержать буквы и цифры, но не может начинаться с цифры;
- имя начинается с большой буквы — именно так записано в материале лекции;
- круглые и фигурные скобки обязательны;
- круглые скобки обозначают функцию и позже используются для аргументов;
- фигурные скобки ограничивают тело функции;
- `return` — зарезервированное слово, которое указывает, что вернуть;
- после `return` функция останавливает действие и возвращает результат.

### Простой пример из лекции

```ts
function Greeting(): string {
  return "Hello World returned";
}
```

### Пример среднего уровня из лекции

```ts
function Sum(numberOne: number, numberTwo: number): number {
  return numberOne + numberTwo;
}
```

> **В лекции изложено невнятно:** правило «имя начинается с большой буквы» показано как часть комментариев, но отдельно не объясняется, является ли это обязательным синтаксическим требованием или выбранным стилем автора.

### Дополнения от AI

TypeScript не требует начинать имя обычной функции с большой буквы. В распространённом стиле обычные функции называют в `camelCase`, например `calculateSum`. Имена с большой буквы чаще встречаются у классов и конструкторов. Это уточнение от AI, а не исправление текста лекции внутри основного конспекта.

```ts
Greeting();
```

и:

```ts
console.log(Greeting());
```

При втором варианте в Output видно:


### Простой пример из лекции

```ts
Greeting();
```

### Пример среднего уровня из лекции

```ts
console.log(Greeting());
```

### Дополнения от AI

`Greeting()` выполняет функцию и получает возвращённую строку. Если результат не сохранить и не передать дальше, он не появится в Output сам по себе. `console.log(Greeting())` сначала вызывает функцию, затем печатает полученное значение.

## 7. Устранение повторения с помощью функции `Print`

Повторяющиеся строки заголовка выносятся в функцию:

```ts
function Print() {
  console.log("\nResult of calculations: ");
  console.log("----------------------");
}
```

После этого задача переписывается:

```ts
const a: number = 5;
const b: number = 10;

Print();
console.log(a + b);

Print();
console.log(a - b);

Print();
console.log(a * b);
```

### Простой пример из лекции

```ts
Print();
```

### Пример среднего уровня из лекции

```ts
Print();
console.log(a + b);

Print();
console.log(a - b);
```

### Дополнения от AI

В этом примере функция не вычисляет сумму или разность. Она отвечает только за повторяющийся заголовок. Это соответствует сформулированной в лекции идее: одна функция — одна определённая задача.

## 8. Возвращаемый тип `string`

Функция `Greeting` явно объявлена с возвращаемым типом `string`:

```ts
function Greeting(): string {
  return "Hello World returned";
}
```

Тип записывается после круглых скобок и двоеточия:

```ts
(): string
```

### Простой пример из лекции

```ts
function Greeting(): string {
  return "Hello World returned";
}
```

### Пример среднего уровня из лекции

```ts
function Outer(): string {
  function Inner(): number {
    return 5;
  }

  return "hello-" + Inner();
}
```

> **В лекции изложено неполно:** в доступном фрагменте не проводится отдельное сравнение явного возвращаемого типа с типом, который TypeScript может вывести автоматически.

### Дополнения от AI

Явная запись `: string` сообщает ожидаемый тип результата и позволяет TypeScript проверять значения в `return`. Например, возврат числа из такой функции вызовет ошибку типов.

## 9. Функция без возвращаемого значения: `void`

В лекции записано:

- функция, которая ничего не возвращает, называется `void function`;
- `void` — один из типов данных TypeScript, в основном используемый для функций;
- для такой функции возвращаемый тип указывается явно.

Пример:

```ts
function Print(): void {
  console.log("Hello World printed");
}
```

Далее выполняется:

```ts
console.log(typeof Print());
```

В Output появляются:

```text
Hello World printed
undefined
```

### Простой пример из лекции

```ts
function Print(): void {
  console.log("Hello World printed");
}
```

### Пример среднего уровня из лекции

```ts
console.log(typeof Print());
```

> **В лекции изложено невнятно:** рядом с `void` записано, что функция «имеет `typeof undefined`». Здесь смешиваются TypeScript-аннотация `void` и результат JavaScript-оператора `typeof` для значения, полученного при вызове функции.

### Дополнения от AI

`void` — тип, которым в TypeScript помечают функцию без полезного возвращаемого значения. При выполнении JavaScript такая функция фактически возвращает `undefined`, поэтому `typeof Print()` выводит строку `"undefined"`. При этом `Print()` сначала выполняет свой `console.log`.

## 10. Тип `never`

В материале указано:

- `never` — ещё один тип данных;
- он используется не только в функциях;
- он подходит функции, которая останавливает выполнение кода, например создаёт ошибку;
- такая функция никогда ничего не возвращает, даже `undefined`;
- это отличается от `void`.

Показанный пример:

```ts
function throwError(): never {
  throw "error";
  // no code after the throw statement is reachable.
}
```

Также показан закомментированный вызов:

```ts
console.log(typeof throwError()); // ошибка
```

### Простой пример из лекции

```ts
function throwError(): never {
  throw "error";
}
```

### Пример среднего уровня по показанной конструкции

```ts
function stopProgram(): never {
  throw "Program stopped";
}
```

Второй пример повторяет форму лекции с другим сообщением и добавлен AI для закрепления.

### Дополнения от AI

`void` означает: функция заканчивается нормально, но полезное значение не возвращает. `never` означает: нормальное завершение функции недостижимо. В лекции это показано через `throw`.

## 11. Локальные переменные внутри функции

```ts
function Sum(): number {
```

```ts
function Sum(): number {

  return a;

```

### Пример среднего уровня из лекции

```ts
function Sum(): number {
```

Фигурные скобки функции образуют область видимости. Обращение к `a` или `b` после закрывающей скобки этой функции не соответствует показанной области видимости.

## 12. Параметры функции и аргументы при вызове

Лектор ставит вопрос: «Что если `a` и `b` должны меняться?» После этого значения передаются в функцию через параметры:

```ts
function Sum(numberOne: number, numberTwo: number): number {
  return numberOne + numberTwo;
}

console.log(Sum(5, 10));
console.log(Sum(1, 2));
```

В Output показаны:

```text
15
3
```

В комментариях лекции указано:

- аргументов может быть сколько нужно, они разделяются запятыми;
- аргументы могут иметь любые типы данных, но типы нужно указывать;
- названия должны что-то означать;
- для названий используется `camelCase`.

### Простой пример из лекции

```ts
function Sum(a: number, b: number): number {
  return a + b;
}
```

### Пример среднего уровня из лекции

```ts
function Sum(numberOne: number, numberTwo: number): number {
  return numberOne + numberTwo;
}

console.log(Sum(5, 10));
console.log(Sum(1, 2));
```

### Дополнения от AI

В объявлении `numberOne` и `numberTwo` — параметры. В вызове `Sum(5, 10)` значения `5` и `10` — аргументы. В самой лекции раздел называется «аргументы функции», но эти два термина полезно различать.

## 14. Необязательный параметр

Для необязательного параметра показан знак `?`:

```ts
function Sum(a: number, b?: number): number {
  if (b) {
    return a + b;
  }

  return a;
}

console.log(Sum(5));
```

В Output показано `5`.

Во время демонстрации в строке с `b?` временно появляется `= 10`, но редактор показывает проблему. Финальная рабочая форма на экране использует `b?: number` и проверку `if (b)`.

### Простой пример из лекции

```ts
function Sum(a: number, b?: number): number {
  return a;
}
```

### Пример среднего уровня из лекции

```ts
function Sum(a: number, b?: number): number {
  if (b) {
    return a + b;
  }

  return a;
}
```

> **В лекции изложено неполно:** не рассматривается случай, когда `b` передан как `0`; условие `if (b)` в таком случае будет ложным.

### Дополнения от AI

Если нужно отличать отсутствие параметра от числа `0`, проверку можно записать явно:

```ts
function sum(a: number, b?: number): number {
  if (b !== undefined) {
    return a + b;
  }

  return a;
}
```

Этот вариант добавлен AI и в лекции не показывался.

## 16. Сохранение результата функции в переменную

Лектор показывает два варианта использования результата:

```ts
console.log(Sum(1, 2));
```

и:

```ts
const sum: number = Sum(1, 2);
console.log(sum);
```

Оба варианта выводят `3`.

### Простой пример из лекции

```ts
console.log(Sum(1, 2));
```

### Пример среднего уровня из лекции

```ts
const sum: number = Sum(1, 2);
console.log(sum);
```

### Дополнения от AI

Сохранённый результат можно использовать несколько раз, не вызывая функцию повторно. В лекции показано именно присваивание результата константе и последующий вывод.

---

## 17. Вложенная функция и её область видимости

Лектор показывает, что функция может находиться внутри другой функции:

```ts
function Outer(): string {
  function Inner(): number {
    return 5;
  }

  return "hello-" + Inner();
}

console.log(Outer());
```

В Output видно:

```text
hello-5
```

В комментарии указано: `Inner()` видна только внутри `Outer()`.

### Простой пример из лекции

```ts
function Outer(): string {
  return "hello";
}
```

### Пример среднего уровня из лекции

```ts
function Outer(): string {
  function Inner(): number {
    return 5;
  }

  return "hello-" + Inner();
}
```

### Дополнения от AI

Вызвать `Inner()` из кода после `Outer()` нельзя, потому что её имя существует только внутри тела `Outer`. `Outer()` при этом может вызывать `Inner()` и использовать её результат.

## 18. Рекурсивная функция

В лекции рекурсивная функция определяется как функция, которая вызывает сама себя.

Показан пример «таблица квадратов»:

```ts
function SquareIt(num: number): number {
  console.log(num);
  const square = num * num;

  return SquareIt(square);
}

SquareIt(2);
```

Функция печатает число, вычисляет его квадрат и снова вызывает себя с новым значением. В Output появляются растущие значения, затем `Infinity` и ошибка:

```text
RangeError: Maximum call stack size exceeded
```

Позже на экране добавляется, но остаётся закомментированным, условие:

```ts
// if (num > 65536) {
//   return;
// }
```

### Простой пример из лекции

```ts
function SquareIt(num: number): number {
  return SquareIt(num * num);
}
```

### Пример среднего уровня из лекции

```ts
function SquareIt(num: number): number {
  console.log(num);
  const square = num * num;
  return SquareIt(square);
}

SquareIt(2);
```

> **В лекции изложено неполно:** в доступных семи частях рекурсивная функция заканчивает работу ошибкой. Условие остановки показано только в комментариях и не приведено к согласованному с `: number` рабочему варианту.

### Дополнения от AI

Рекурсии нужен базовый случай — условие, при котором новый рекурсивный вызов не выполняется. Например:

```ts
function squareUntilLimit(num: number): number {
  if (num > 65_536) {
    return num;
  }

  const square = num * num;
  return squareUntilLimit(square);
}
```

Это вариант AI для пояснения. Он не является кодом лектора и не заменяет зафиксированный в основной части пример с ошибкой.

## 1. Остановка рекурсии

В предыдущей части функция вызывала саму себя без остановки. Здесь в неё добавляется проверка значения аргумента. Если число стало больше `65536`, выполняется `return`, и дальнейшие рекурсивные вызовы прекращаются.

### Пример из лекции

```ts
function SquareIt(num: number): number | undefined {
  if (num > 65536) {
    return;
  }

  console.log(num);
  const square = num * num;

  return SquareIt(square);
}

SquareIt(2);
```

Последовательность значений в консоли:

```text
2
4
16
256
65536
```

В сигнатуре указан тип `number | undefined`, потому что при выполнении `return;` функция ничего не возвращает. В ходе разбора лектор также меняет этот вариант так, чтобы в условии остановки возвращалось число и тип результата можно было указать как `number`.

### Дополнения от AI

Условие, которое прекращает рекурсивные вызовы, обычно называют **базовым случаем**. Без него функция будет вызывать себя, пока не будет переполнен стек вызовов.

Простой пример с числовым результатом:

```ts
function countdown(num: number): number {
  if (num === 0) {
    return 0;
  }

  console.log(num);
  return countdown(num - 1);
}

countdown(3);
```

Пример среднего уровня — сумма чисел от `1` до `n`:

```ts
function sumTo(n: number): number {
  if (n === 1) {
    return 1;
  }

  return n + sumTo(n - 1);
}

console.log(sumTo(4)); // 10
```

## 2. Function declaration — объявление функции

Лектор называет первый способ записи функции **function declaration**. Функции дают имя, а затем вызывают её по этому имени.

### Пример из лекции

```ts
function Print(): void {
  console.log("Hello World");
}

Print();
```

Лектор переставляет вызов выше объявления:

```ts
Print();

function Print(): void {
  console.log("Hello World");
}
```

Код продолжает работать. В лекции это объясняется **function hoisting**: объявление функции поднимается, поэтому функцию можно вызвать до строки, на которой она записана в файле.

### Дополнения от AI

Простой пример:

```ts
sayHello();

function sayHello(): void {
  console.log("Hello!");
}
```

Пример среднего уровня:

```ts
console.log(calculateArea(5, 3)); // 15

function calculateArea(width: number, height: number): number {
  return width * height;
}
```

---

## 3. Function expression — функциональное выражение

Второй способ — создать функцию и присвоить её переменной. В лекции сначала используется обычное объявление `Sum`, а затем результат её вызова сохраняется в переменную:

```ts
function Sum(a: number, b: number): number {
  return a + b;
}

let sum = Sum(1, 2);
console.log(sum);
```

После этого функция записывается непосредственно в переменную:

```ts
const sum = function Sum(a: number, b: number): number {
  return a + b;
};

console.log(sum(1, 2));
```

Лектор подчёркивает: function expression не поднимается наверх кода так же, как function declaration, поэтому вызвать такую функцию до её объявления нельзя.

> **В лекции изложено невнятно:** связь function expression с переменной и завершающей точкой с запятой проговаривается не вполне последовательно. Также не разделены именованное и анонимное функциональные выражения.

### Дополнения от AI

Function expression — это функция, которая находится в правой части присваивания. Имя внутри неё может отсутствовать:

```ts
const printMessage = function (): void {
  console.log("Сообщение");
};

printMessage();
```

Вызов до инициализации переменной приводит к ошибке:

```ts
// multiply(2, 3); // Нельзя вызвать здесь

const multiply = function (a: number, b: number): number {
  return a * b;
};

console.log(multiply(2, 3)); // 6
```

Точка с запятой завершает инструкцию присваивания функции переменной. Она не является признаком, который сам по себе превращает функцию в function expression.

## 4. Arrow function — стрелочная функция

Третий способ записи — стрелочная функция. В её синтаксисе после параметров ставится стрелка `=>`.

### Пример из лекции

```ts
const sum = (a: number, b: number): number => {
  return a + b;
};

console.log(sum(1, 2));
```

Если тело функции состоит только из возврата одного выражения, фигурные скобки и `return` можно опустить:

```ts
const sum = (a: number, b: number): number => a + b;

console.log(sum(1, 2));
```

> **В лекции изложено невнятно:** стрелка объясняется как способ сообщить TypeScript, что запись является функцией. Формальное устройство синтаксиса стрелочной функции отдельно не разбирается.

### Дополнения от AI

Слева от `=>` находятся параметры, справа — тело функции или единственное возвращаемое выражение.

Простой пример:

```ts
const double = (num: number): number => num * 2;

console.log(double(5)); // 10
```

Пример среднего уровня:

```ts
const createGreeting = (name: string, age: number): string => {
  const message = `Привет, ${name}!`;
  return `${message} Тебе ${age}.`;
};

console.log(createGreeting("Anna", 25));
```

## 5. Три способа записи функции

Лектор сводит рассмотренные варианты в один пример.

```ts
// 1. Function declaration
function myFunction1(): string {
  return "";
}

// 2. Function expression
const myFunction2 = function (): string {
  return "";
};

// 3. Arrow function
const myFunction3 = (): string => {
  return "";
};
```

| Способ | Основной признак в записи | Hoisting по объяснению лектора |
|---|---|---|
| Function declaration | Начинается с `function`, есть имя функции | Можно вызвать до объявления |
| Function expression | Функция присваивается переменной | Нельзя вызвать до объявления |
| Arrow function | Используется `=>` | В лекции отдельно не обсуждается |

### Дополнения от AI

Одна и та же операция в трёх вариантах:

```ts
function add1(a: number, b: number): number {
  return a + b;
}

const add2 = function (a: number, b: number): number {
  return a + b;
};

const add3 = (a: number, b: number): number => a + b;
```

Во всех трёх случаях вызов после объявления выглядит одинаково:

```ts
console.log(add1(2, 3));
console.log(add2(2, 3));
console.log(add3(2, 3));
```

## 6. Функции и методы

Лектор говорит, что методы — это функции, относящиеся к определённой области. В качестве примера упоминаются методы строк: их реализация уже написана, а программист вызывает метод, передаёт ему нужные аргументы и использует возвращаемый результат.

Главная практическая мысль лекции:

- есть функция или метод;
- она может принимать аргументы;
- она выполняет действие;
- она может вернуть результат, который затем используется в коде.

> **В лекции изложено невнятно:** определение метода через «функцию внутри определённой области действия» дано без конкретного объекта и без кода, поэтому граница между обычной функцией и методом остаётся неочевидной.

### Дополнения от AI

Метод вызывается через значение или объект с помощью точки:

```ts
const word: string = "typescript";
const upperWord: string = word.toUpperCase();

console.log(upperWord); // TYPESCRIPT
```

Здесь `toUpperCase()` — метод строки `word`.

Пример среднего уровня:

```ts
const names: string[] = ["anna", "boris"];
const firstName: string | undefined = names.at(0);

console.log(firstName); // anna
```

Здесь `at(0)` — метод массива: он принимает индекс и возвращает элемент либо `undefined`.

## 7. Callback-функция и метод массива `map`

Лектор ставит задачу: есть массив чисел, каждый элемент нужно умножить на `2`.

### Первый вариант — цикл

```ts
const arr: number[] = [1, 2, 4, 10, 12];
const newArr: number[] = [];

for (let i = 0; i < arr.length; i++) {
  newArr.push(arr[i] * 2);
}

console.log(newArr); // [2, 4, 8, 20, 24]
```

### Второй вариант — отдельная функция и `map`

```ts
const arr: number[] = [1, 2, 4, 10, 12];

function Multiply(el: number): number {
  return el * 2;
}

const newArr: number[] = arr.map(Multiply);

console.log(newArr); // [2, 4, 8, 20, 24]
```

По объяснению лектора:

- метод `map` принимает функцию как аргумент;
- такая функция называется **callback function**;
- callback вызывается столько раз, сколько элементов находится в массиве;
- `map` возвращает новый массив, поэтому результат можно сохранить в переменную;
- исходный массив при этом не меняется.

> **В лекции изложено невнятно:** комментарии о том, что именно является аргументом и что можно переименовать, сформулированы фрагментарно.

### Дополнения от AI

В вызове `arr.map(Multiply)` имя `Multiply` передаётся без круглых скобок: в `map` передаётся сама функция, а не заранее вычисленный результат её вызова.

Для каждого элемента массива `map` вызывает callback и складывает возвращённые значения в новый массив:

```ts
const prices: number[] = [10, 20, 30];

function addTax(price: number): number {
  return price * 1.2;
}

const pricesWithTax: number[] = prices.map(addTax);
console.log(pricesWithTax); // [12, 24, 36]
```

## 8. Callback внутри `map`

Отдельную callback-функцию можно не объявлять заранее. В лекции функция записывается прямо в аргументе метода `map`.

### Полная запись

```ts
const arr: number[] = [1, 2, 4, 10, 12];

const newArr: number[] = arr.map((el: number) => {
  return el * 2;
});

console.log(newArr);
```

### Сокращённая запись

```ts
const arr: number[] = [1, 2, 4, 10, 12];

const newArr: number[] = arr.map((el: number) => el * 2);

console.log(newArr); // [2, 4, 8, 20, 24]
```

Лектор также показывает подсказку редактора: callback метода `map` может получать значение текущего элемента, его индекс и исходный массив. В основном примере используется только значение элемента.

### Дополнения от AI

Пример с текущим элементом и индексом:

```ts
const names: string[] = ["Anna", "Boris", "Olga"];

const numberedNames: string[] = names.map(
  (name: string, index: number): string => `${index + 1}. ${name}`
);

console.log(numberedNames);
// ["1. Anna", "2. Boris", "3. Olga"]
```

## 9. Практический пример: Цельсий → Фаренгейт

В конце фрагмента лектор создаёт массив температур по Цельсию и с помощью `map` получает новый массив температур по Фаренгейту.

```ts
const celsiusTemperature: number[] = [0, 10, 20, 30];

const fahrenheitTemperature: number[] = celsiusTemperature.map(
  (celsius: number) => {
    return celsius * 9 / 5 + 32;
  }
);

console.log(fahrenheitTemperature);
```

Функция внутри `map` выполняется отдельно для каждого значения `celsius`. Результат каждого вызова попадает в новый массив `fahrenheitTemperature`.

### Дополнения от AI

Тот же пример в сокращённой форме:

```ts
const celsiusTemperature: number[] = [0, 10, 20, 30];

const fahrenheitTemperature: number[] = celsiusTemperature.map(
  (celsius: number): number => celsius * 9 / 5 + 32
);

console.log(fahrenheitTemperature); // [32, 50, 68, 86]
```

## 1. Параметры callback-функции в `map`

Лектор возвращается к методу `map` и показывает общую форму callback-функции:

```ts
const res = arr.map((el, index, array) => {
  return ...;
});
```

Назначение параметров по объяснению лектора:

- `el` — текущий элемент массива;
- `index` — индекс текущего элемента;
- `array` — исходный массив, с которым начали работать.

Использовать все три параметра необязательно. Если нужен только текущий элемент, в callback можно указать только его.

> **В лекции изложено невнятно:** раздел назван `optional parameters`, но не уточняется разница между необязательным параметром TypeScript, который обозначается знаком `?`, и возможностью не объявлять в callback параметры `index` и `array`, если они не используются.

### Дополнения от AI

Метод `map` при каждом вызове callback передаёт три значения. Callback может объявить только те параметры, которые нужны в его теле.

Простой пример — используется только элемент:

```ts
const numbers: number[] = [1, 2, 3];

const doubled: number[] = numbers.map(
  (el: number): number => el * 2
);

console.log(doubled); // [2, 4, 6]
```

Пример среднего уровня — используются элемент и индекс:

```ts
const names: string[] = ["Anna", "Boris", "Olga"];

const numberedNames: string[] = names.map(
  (name: string, index: number): string => `${index + 1}. ${name}`
);

console.log(numberedNames);
// ["1. Anna", "2. Boris", "3. Olga"]
```

## 2. Изменение всех элементов, кроме элемента с заданным индексом

Лектор ставит задачу: умножить каждый элемент массива на `2`, кроме третьего элемента.

Так как индексация начинается с `0`, третий элемент имеет индекс `2`.

### Пример из лекции

```ts
const arr: number[] = [1, 2, 3, 4, 5];

const newArr: number[] = arr.map(
  (el: number, index: number): number => {
    if (index !== 2) {
      return el * 2;
    }

    return el;
  }
);

console.log(newArr); // [2, 4, 3, 8, 10]
```

Логика callback:

1. Для каждого элемента проверяется `index`.
2. Если индекс не равен `2`, возвращается удвоенное значение.
3. Если индекс равен `2`, возвращается исходный элемент.
4. `map` собирает возвращённые значения в новый массив.

### Дополнения от AI

Простой аналогичный пример — не изменять первый элемент:

```ts
const prices: number[] = [10, 20, 30];

const result: number[] = prices.map(
  (price: number, index: number): number => {
    if (index === 0) {
      return price;
    }

    return price + 5;
  }
);

console.log(result); // [10, 25, 35]
```

## 3. Метод `forEach`

По объяснению лектора, `forEach`, как и `map`, принимает callback-функцию. Метод проходит по элементам массива, но не создаёт новый массив.

### Пример из лекции

```ts
const arr: number[] = [1, 2, 3];

arr.forEach((el: number) => {
  console.log(el);
});
```

В консоль последовательно выводятся:

```text
1
2
3
```

> **В лекции изложено невнятно:** фраза о том, что `forEach` «ничего не создаёт или не меняет», слишком общая. В примере действительно только выполняется `console.log`, но границы возможного использования метода отдельно не объясняются.

### Дополнения от AI

Практическое различие примеров лекции:

- `map` используется, когда из элементов нужно получить **новый массив**;
- `forEach` используется, когда для каждого элемента нужно выполнить действие, а новый массив не требуется.

Простой пример:

```ts
const fruits: string[] = ["apple", "pear", "orange"];

fruits.forEach((fruit: string) => {
  console.log(fruit);
});
```

Пример среднего уровня — подсчёт общей суммы через внешнюю переменную:

```ts
const prices: number[] = [10, 15, 25];
let total: number = 0;

prices.forEach((price: number) => {
  total = total + price;
});

console.log(total); // 50
```

## 4. Метод `filter`

По объяснению лектора, `filter`:

- фильтрует элементы массива по созданному условию;
- работает похоже на `map`, потому что принимает callback;
- возвращает новый массив.

Callback должен вернуть результат проверки условия. В новый массив попадают элементы, для которых условие истинно.

### Пример из лекции: слова длиннее шести символов

```ts
const words: string[] = [
  "hello",
  "afternoon",
  "fun",
  "paranthesis",
  "hammer"
];

const filteredWords: string[] = words.filter(
  (word: string): boolean => word.length > 6
);

console.log(filteredWords);
// ["afternoon", "paranthesis"]
```

### Пример из лекции: чётные числа

```ts
const numbers: number[] = [1, 2, 3, 4];

const evenNumbers: number[] = numbers.filter(
  (num: number): boolean => num % 2 === 0
);

console.log(evenNumbers); // [2, 4]
```

### Дополнения от AI

Простой пример — оставить положительные числа:

```ts
const values: number[] = [-2, 0, 3, 7];

const positive: number[] = values.filter(
  (value: number): boolean => value > 0
);

console.log(positive); // [3, 7]
```

Пример среднего уровня — оставить имена, начинающиеся с `A`:

```ts
const names: string[] = ["Anna", "Boris", "Alice", "Olga"];

const namesWithA: string[] = names.filter(
  (name: string): boolean => name.startsWith("A")
);

console.log(namesWithA); // ["Anna", "Alice"]
```

## 5. Метод `includes`

Лектор показывает, что `includes` проверяет наличие элемента в массиве и возвращает `true` или `false`.

### Пример из лекции

```ts
const arr: string[] = ["dog", "cat", "bird"];

console.log(arr.includes("dog"));  // true
console.log(arr.includes("fish")); // false
```

У метода показаны два параметра:

- `searchElement` — элемент, который нужно найти;
- `fromIndex` — индекс, начиная с которого нужно искать; отсчёт ведётся от `0`.

```ts
console.log(["a", "b", "c"].includes("a"));    // true
console.log(["a", "b", "c"].includes("b", 1)); // true
console.log(["a", "b", "c"].includes("b", 3)); // false
```

> **В лекции изложено невнятно:** в комментарии говорится о поиске элементов, «соответствующих условию», хотя в показанном коде callback или отдельное условие не используются — передаётся конкретное искомое значение.

### Дополнения от AI

В рамках показанного примера удобнее формулировать так: `includes` проверяет, есть ли в массиве указанное значение.

Простой пример:

```ts
const roles: string[] = ["admin", "editor", "viewer"];

console.log(roles.includes("editor")); // true
```

Пример среднего уровня с начальным индексом:

```ts
const statuses: string[] = ["new", "done", "new"];

console.log(statuses.includes("new", 1)); // true
console.log(statuses.includes("done", 2)); // false
```

## 6. Метод `reduce`

Лектор представляет общую форму метода:

```ts
const res = arr.reduce(callbackFunction, initialValue);
```

По материалу лекции, `reduce` используется, чтобы «свернуть» массив в одно значение. Результатом может быть число, строка, другой массив и так далее.

Лектор выделяет два аргумента метода:

1. callback-функция;
2. начальное значение `initialValue`.

Метод проходит по элементам массива и последовательно передаёт результат предыдущего вычисления в следующий вызов callback. В конце возвращается одно итоговое значение.

### Пример из лекции: сумма элементов

```ts
const arr: number[] = [1, 2, 3, 4];

const sum: number = arr.reduce(
  (accumulator: number, currentValue: number): number => {
    return accumulator + currentValue;
  }
);

console.log(sum); // 10
```

### `accumulator`

По объяснению лектора:

- это первый аргумент callback;
- его также часто называют `acc`;
- он собирает результаты вычислений;
- если начальное значение не передано, в начале он равен первому элементу массива.

### `currentValue`

По объяснению лектора:

- это второй аргумент callback;
- его также называют `value` или `item`;
- он содержит текущее значение элемента массива;
- его значение меняется при каждой итерации.

### Начальное значение

Лектор добавляет к вызову `reduce` начальное значение `100`:

```ts
const arr: number[] = [1, 2, 3, 4];

const sum: number = arr.reduce(
  (accumulator: number, currentValue: number): number => {
    return accumulator + currentValue;
  },
  100
);

console.log(sum); // 110
```

После замены начального значения на `0` результат снова равен `10`:

```ts
const sum: number = arr.reduce(
  (accumulator: number, currentValue: number): number => {
    return accumulator + currentValue;
  },
  0
);
```

> **В лекции изложено неполно:** показано поведение `accumulator` без начального значения и с ним, но последовательность значений по каждой итерации явно не расписана.

### Дополнения от AI

Для массива `[1, 2, 3, 4]` и начального значения `0` вычисления можно представить так:

| Итерация | `accumulator` до сложения | `currentValue` | Новый результат |
|---:|---:|---:|---:|
| 1 | 0 | 1 | 1 |
| 2 | 1 | 2 | 3 |
| 3 | 3 | 3 | 6 |
| 4 | 6 | 4 | 10 |

Простой пример — произведение чисел:

```ts
const numbers: number[] = [2, 3, 4];

const product: number = numbers.reduce(
  (acc: number, item: number): number => acc * item,
  1
);

console.log(product); // 24
```

Пример среднего уровня — собрать одну строку:

```ts
const words: string[] = ["TypeScript", "is", "useful"];

const sentence: string = words.reduce(
  (acc: string, word: string): string => `${acc} ${word}`,
  ""
);

console.log(sentence); // " TypeScript is useful"
```

## 7. Сравнение рассмотренных методов

| Метод | Принимает callback | Что возвращает в примерах лекции | Основное назначение в лекции |
|---|---:|---|---|
| `map` | Да | Новый массив | Преобразовать каждый элемент |
| `forEach` | Да | Новый массив не создаётся | Выполнить действие для каждого элемента |
| `filter` | Да | Новый отфильтрованный массив | Оставить элементы по условию |
| `includes` | Нет | `true` или `false` | Проверить наличие значения |
| `reduce` | Да | Одно итоговое значение | Последовательно объединить результаты |

### Дополнения от AI

Короткая памятка выбора:

```ts
const numbers: number[] = [1, 2, 3, 4];

numbers.map((n: number) => n * 2);          // [2, 4, 6, 8]
numbers.forEach((n: number) => console.log(n));
numbers.filter((n: number) => n % 2 === 0); // [2, 4]
numbers.includes(3);                         // true
numbers.reduce((acc: number, n: number) => acc + n, 0); // 10
```
