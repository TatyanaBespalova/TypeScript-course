## 1. Повторение: три части цикла `for`

В начале записи продолжается работа с циклом `for`. На экране показана его общая форма:

```ts
for (инициализация; условие; изменение) {
  // тело цикла
}
```

Лектор по очереди убирает отдельные части цикла и показывает варианты вроде:

```ts
let i = 0;

for (;;) {
}
```

и:

```ts
for (let i = 0; ; i++) {
}
```

### Простой пример из лекции

```ts
for (let i = 0; i < 5; i++) {
}
```

### Пример среднего уровня из лекции

```ts
let i = 0;

for (;;) {
  // все три части заголовка пропущены
}
```

> **В лекции изложено неполно:** на показанном фрагменте пустые части цикла рассматриваются как синтаксические варианты, но законченный безопасный пример с условием выхода не демонстрируется.

### Дополнения от AI

`for (;;)` создаёт цикл без условия завершения. Для учебного безопасного примера нужен явный выход:

```ts
let i = 0;

for (;;) {
  if (i === 3) break;
  console.log(i);
  i++;
}
```

Этот пример добавлен AI и в записи не показывался.

## 2. Перебор массива: фиксированная граница и `arr.length`

Лектор создаёт массив и перебирает его циклом:

```ts
let arr: number[] = [1, 2, 3];
let str: string = "";

for (let i = 0; i < arr.length; i++) {
  str += arr[i] + ", ";
}

console.log(str);
```

В Output показан результат:

```text
1, 2, 3,
```

Перед использованием `arr.length` на экране присутствует вариант с фиксированной границей:

```ts
for (let i = 0; i < 5; i++) {
  str += arr[i];
}
```

### Простой пример из лекции

```ts
let arr: number[] = [1, 2, 3];

for (let i = 0; i < arr.length; i++) {
  console.log(arr[i]);
}
```

### Пример среднего уровня из лекции

```ts
let arr: number[] = [1, 2, 3];
let str = "";

for (let i = 0; i < arr.length; i++) {
  str += arr[i] + ", ";
}

console.log(str);
```

### Дополнения от AI

Для массива из трёх элементов условие `i < 5` приводит к попыткам прочитать индексы `3` и `4`, которых нет. Вариант `i < arr.length` автоматически использует реальную длину массива и остаётся корректным при изменении количества элементов.

## 3. Массив, содержащий числа и вложенный массив

В записи показан тип:

```ts
let arr: (number | number[])[] = [1, 2, 3, [10, 11, 12]];
```

Затем лектор начинает строить вложенный цикл и обращаться к элементу так:

```ts
arr[i][j];
```

Редактор подчёркивает это выражение как проблему. Причина прямо на экране не оформляется в законченный пример.

### Простой пример из лекции

```ts
let arr: (number | number[])[] = [1, 2, 3, [10, 11, 12]];
```

### Пример среднего уровня из лекции

```ts
for (let i = 0; i < arr.length; i++) {
  for (let j = 0; j < 5; j++) {
    arr[i][j];
  }
}
```

> **В лекции изложено невнятно:** показанный вложенный цикл остаётся с ошибкой и затем очищается. Готовое решение в этой части не показывается.

### Дополнения от AI

Элемент `arr[i]` имеет тип `number | number[]`. Индекс `[j]` можно применять только после проверки, что текущий элемент действительно является массивом:

```ts
for (let i = 0; i < arr.length; i++) {
  const item = arr[i];

  if (Array.isArray(item)) {
    for (let j = 0; j < item.length; j++) {
      console.log(item[j]);
    }
  } else {
    console.log(item);
  }
}
```

Это решение предложено AI; в лекции оно не было доведено до такого вида.

## 4. Что такое функция и зачем она нужна

В файле лекции записано:

- функция — ещё один тип данных в TypeScript;
- это код, написанный отдельно от остального кода и выполняющий одну определённую задачу;
- функции нужны для многократного использования кода;
- функция помогает не повторять одинаковый код;
- функции помогают создавать легко читаемый, чистый код.

Для демонстрации повторения кода сначала выводятся одинаковые заголовки перед несколькими вычислениями:

```ts
const a: number = 5;
const b: number = 10;

console.log("\nResult of calculations: ");
console.log("----------------------");
console.log(a + b);

console.log("\nResult of calculations: ");
console.log("----------------------");
console.log(a - b);

console.log("\nResult of calculations: ");
console.log("----------------------");
console.log(a * b);
```

В Output видны результаты `15`, `-5` и `50`.

### Простой пример из лекции

```ts
console.log(a + b);
```

### Пример среднего уровня из лекции

```ts
console.log("\nResult of calculations: ");
console.log("----------------------");
console.log(a + b);
```

### Дополнения от AI

Повторяющиеся две строки заголовка становятся кандидатом на отдельную функцию. Именно этот пример подводит к следующему разделу.

## 5. Объявление функции

Лектор показывает шаблон объявления:

```ts
function ИмяФункции(): тип {
  // тело функции
  return результат;
}
```

В комментариях к шаблону указано:

- `function` — зарезервированное слово;
- имя функции должно понятно описывать, что делает функция;
- имя может содержать буквы и цифры, но не может начинаться с цифры;
- имя начинается с большой буквы — именно так записано в материале лекции;
- круглые и фигурные скобки обязательны;
- круглые скобки обозначают функцию и позже используются для аргументов;
- фигурные скобки ограничивают тело функции;
- `return` — зарезервированное слово, которое указывает, что вернуть;
- после `return` функция останавливает действие и возвращает результат.

### Простой пример из лекции

```ts
function Greeting(): string {
  return "Hello World returned";
}
```

### Пример среднего уровня из лекции

```ts
function Sum(numberOne: number, numberTwo: number): number {
  return numberOne + numberTwo;
}
```

> **В лекции изложено невнятно:** правило «имя начинается с большой буквы» показано как часть комментариев, но отдельно не объясняется, является ли это обязательным синтаксическим требованием или выбранным стилем автора.

### Дополнения от AI

TypeScript не требует начинать имя обычной функции с большой буквы. В распространённом стиле обычные функции называют в `camelCase`, например `calculateSum`. Имена с большой буквы чаще встречаются у классов и конструкторов. Это уточнение от AI, а не исправление текста лекции внутри основного конспекта.

## 6. Объявление функции и её вызов — разные действия

Показана функция:

```ts
function Greeting(): string {
  return "Hello World returned";
}
```

Затем рассматриваются варианты:

```ts
Greeting();
```

и:

```ts
console.log(Greeting());
```

При втором варианте в Output видно:

```text
Hello World returned
```

### Простой пример из лекции

```ts
Greeting();
```

### Пример среднего уровня из лекции

```ts
console.log(Greeting());
```

### Дополнения от AI

`Greeting()` выполняет функцию и получает возвращённую строку. Если результат не сохранить и не передать дальше, он не появится в Output сам по себе. `console.log(Greeting())` сначала вызывает функцию, затем печатает полученное значение.

## 7. Устранение повторения с помощью функции `Print`

Повторяющиеся строки заголовка выносятся в функцию:

```ts
function Print() {
  console.log("\nResult of calculations: ");
  console.log("----------------------");
}
```

После этого задача переписывается:

```ts
const a: number = 5;
const b: number = 10;

Print();
console.log(a + b);

Print();
console.log(a - b);

Print();
console.log(a * b);
```

### Простой пример из лекции

```ts
Print();
```

### Пример среднего уровня из лекции

```ts
Print();
console.log(a + b);

Print();
console.log(a - b);
```

### Дополнения от AI

В этом примере функция не вычисляет сумму или разность. Она отвечает только за повторяющийся заголовок. Это соответствует сформулированной в лекции идее: одна функция — одна определённая задача.

## 8. Возвращаемый тип `string`

Функция `Greeting` явно объявлена с возвращаемым типом `string`:

```ts
function Greeting(): string {
  return "Hello World returned";
}
```

Тип записывается после круглых скобок и двоеточия:

```ts
(): string
```

### Простой пример из лекции

```ts
function Greeting(): string {
  return "Hello World returned";
}
```

### Пример среднего уровня из лекции

```ts
function Outer(): string {
  function Inner(): number {
    return 5;
  }

  return "hello-" + Inner();
}
```

> **В лекции изложено неполно:** в доступном фрагменте не проводится отдельное сравнение явного возвращаемого типа с типом, который TypeScript может вывести автоматически.

### Дополнения от AI

Явная запись `: string` сообщает ожидаемый тип результата и позволяет TypeScript проверять значения в `return`. Например, возврат числа из такой функции вызовет ошибку типов.

## 9. Функция без возвращаемого значения: `void`

В лекции записано:

- функция, которая ничего не возвращает, называется `void function`;
- `void` — один из типов данных TypeScript, в основном используемый для функций;
- для такой функции возвращаемый тип указывается явно.

Пример:

```ts
function Print(): void {
  console.log("Hello World printed");
}
```

Далее выполняется:

```ts
console.log(typeof Print());
```

В Output появляются:

```text
Hello World printed
undefined
```

### Простой пример из лекции

```ts
function Print(): void {
  console.log("Hello World printed");
}
```

### Пример среднего уровня из лекции

```ts
console.log(typeof Print());
```

> **В лекции изложено невнятно:** рядом с `void` записано, что функция «имеет `typeof undefined`». Здесь смешиваются TypeScript-аннотация `void` и результат JavaScript-оператора `typeof` для значения, полученного при вызове функции.

### Дополнения от AI

`void` — тип, которым в TypeScript помечают функцию без полезного возвращаемого значения. При выполнении JavaScript такая функция фактически возвращает `undefined`, поэтому `typeof Print()` выводит строку `"undefined"`. При этом `Print()` сначала выполняет свой `console.log`.

## 10. Тип `never`

В материале указано:

- `never` — ещё один тип данных;
- он используется не только в функциях;
- он подходит функции, которая останавливает выполнение кода, например создаёт ошибку;
- такая функция никогда ничего не возвращает, даже `undefined`;
- это отличается от `void`.

Показанный пример:

```ts
function throwError(): never {
  throw "error";
  // no code after the throw statement is reachable.
}
```

Также показан закомментированный вызов:

```ts
console.log(typeof throwError()); // ошибка
```

### Простой пример из лекции

```ts
function throwError(): never {
  throw "error";
}
```

### Пример среднего уровня по показанной конструкции

```ts
function stopProgram(): never {
  throw "Program stopped";
}
```

Второй пример повторяет форму лекции с другим сообщением и добавлен AI для закрепления.

### Дополнения от AI

`void` означает: функция заканчивается нормально, но полезное значение не возвращает. `never` означает: нормальное завершение функции недостижимо. В лекции это показано через `throw`.

## 11. Локальные переменные внутри функции

В функции `Sum` создаются переменные `a` и `b`:


### Дополнения от AI

Фигурные скобки функции образуют область видимости. Обращение к `a` или `b` после закрывающей скобки этой функции не соответствует показанной области видимости.

## 12. Параметры функции и аргументы при вызове

Лектор ставит вопрос: «Что если `a` и `b` должны меняться?» После этого значения передаются в функцию через параметры:

```ts
function Sum(numberOne: number, numberTwo: number): number {
  return numberOne + numberTwo;
}

console.log(Sum(5, 10));
console.log(Sum(1, 2));
```

В Output показаны:

```text
15
3
```

В комментариях лекции указано:

- аргументов может быть сколько нужно, они разделяются запятыми;
- аргументы могут иметь любые типы данных, но типы нужно указывать;
- названия должны что-то означать;
- для названий используется `camelCase`.

### Простой пример из лекции

```ts
function Sum(a: number, b: number): number {
  return a + b;
}
```

### Пример среднего уровня из лекции

```ts
function Sum(numberOne: number, numberTwo: number): number {
  return numberOne + numberTwo;
}

console.log(Sum(5, 10));
console.log(Sum(1, 2));
```

### Дополнения от AI

В объявлении `numberOne` и `numberTwo` — параметры. В вызове `Sum(5, 10)` значения `5` и `10` — аргументы. В самой лекции раздел называется «аргументы функции», но эти два термина полезно различать.

## 14. Необязательный параметр

Для необязательного параметра показан знак `?`:

```ts
function Sum(a: number, b?: number): number {
  if (b) {
    return a + b;
  }

  return a;
}

console.log(Sum(5));
```

В Output показано `5`.

Во время демонстрации в строке с `b?` временно появляется `= 10`, но редактор показывает проблему. Финальная рабочая форма на экране использует `b?: number` и проверку `if (b)`.

### Простой пример из лекции

```ts
function Sum(a: number, b?: number): number {
  return a;
}
```

### Пример среднего уровня из лекции

```ts
function Sum(a: number, b?: number): number {
  if (b) {
    return a + b;
  }

  return a;
}
```

> **В лекции изложено неполно:** не рассматривается случай, когда `b` передан как `0`; условие `if (b)` в таком случае будет ложным.

### Дополнения от AI

Если нужно отличать отсутствие параметра от числа `0`, проверку можно записать явно:

```ts
function sum(a: number, b?: number): number {
  if (b !== undefined) {
    return a + b;
  }

  return a;
}
```

Этот вариант добавлен AI и в лекции не показывался.

## 17. Вложенная функция и её область видимости

Лектор показывает, что функция может находиться внутри другой функции:

```ts
function Outer(): string {
  function Inner(): number {
    return 5;
  }

  return "hello-" + Inner();
}

console.log(Outer());
```

В Output видно:

```text
hello-5
```

В комментарии указано: `Inner()` видна только внутри `Outer()`.

### Простой пример из лекции

```ts
function Outer(): string {
  return "hello";
}
```

### Пример среднего уровня из лекции

```ts
function Outer(): string {
  function Inner(): number {
    return 5;
  }

  return "hello-" + Inner();
}
```

### Дополнения от AI

Вызвать `Inner()` из кода после `Outer()` нельзя, потому что её имя существует только внутри тела `Outer`. `Outer()` при этом может вызывать `Inner()` и использовать её результат.

## 18. Рекурсивная функция

В лекции рекурсивная функция определяется как функция, которая вызывает сама себя.

Показан пример «таблица квадратов»:

```ts
function SquareIt(num: number): number {
  console.log(num);
  const square = num * num;

  return SquareIt(square);
}

SquareIt(2);
```

Функция печатает число, вычисляет его квадрат и снова вызывает себя с новым значением. В Output появляются растущие значения, затем `Infinity` и ошибка:

```text
RangeError: Maximum call stack size exceeded
```

Позже на экране добавляется, но остаётся закомментированным, условие:

```ts
// if (num > 65536) {
//   return;
// }
```

### Простой пример из лекции

```ts
function SquareIt(num: number): number {
  return SquareIt(num * num);
}
```

### Пример среднего уровня из лекции

```ts
function SquareIt(num: number): number {
  console.log(num);
  const square = num * num;
  return SquareIt(square);
}

SquareIt(2);
```

> **В лекции изложено неполно:** в доступных семи частях рекурсивная функция заканчивает работу ошибкой. Условие остановки показано только в комментариях и не приведено к согласованному с `: number` рабочему варианту.

### Дополнения от AI

Рекурсии нужен базовый случай — условие, при котором новый рекурсивный вызов не выполняется. Например:

```ts
function squareUntilLimit(num: number): number {
  if (num > 65_536) {
    return num;
  }

  const square = num * num;
  return squareUntilLimit(square);
}
```

Это вариант AI для пояснения. Он не является кодом лектора и не заменяет зафиксированный в основной части пример с ошибкой.

## 19. Краткая памятка

| Задача | Конструкция |
| --- | --- |
| Объявить функцию | `function Name() {}` |
| Указать возвращаемый тип | `function Name(): string {}` |
| Вернуть значение | `return value` |
| Вызвать функцию | `Name()` |
| Функция без полезного результата | `(): void` |
| Функция, которая не завершается нормально | `(): never` |
| Обязательный параметр | `a: number` |
| Параметр по умолчанию | `b: number = 10` |
| Необязательный параметр | `b?: number` |
| Сохранить результат | `const result = Sum(1, 2)` |
| Объявить вложенную функцию | `function Outer() { function Inner() {} }` |
| Рекурсивный вызов | функция вызывает саму себя |
