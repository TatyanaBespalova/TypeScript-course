## 1. Параметры callback-функции в `map`

Лектор возвращается к методу `map` и показывает общую форму callback-функции:

```ts
const res = arr.map((el, index, array) => {
  return ...;
});
```

Назначение параметров по объяснению лектора:

- `el` — текущий элемент массива;
- `index` — индекс текущего элемента;
- `array` — исходный массив, с которым начали работать.

Использовать все три параметра необязательно. Если нужен только текущий элемент, в callback можно указать только его.

> **В лекции изложено невнятно:** раздел назван `optional parameters`, но не уточняется разница между необязательным параметром TypeScript, который обозначается знаком `?`, и возможностью не объявлять в callback параметры `index` и `array`, если они не используются.

### Дополнения от AI

Метод `map` при каждом вызове callback передаёт три значения. Callback может объявить только те параметры, которые нужны в его теле.

Простой пример — используется только элемент:

```ts
const numbers: number[] = [1, 2, 3];

const doubled: number[] = numbers.map(
  (el: number): number => el * 2
);

console.log(doubled); // [2, 4, 6]
```

Пример среднего уровня — используются элемент и индекс:

```ts
const names: string[] = ["Anna", "Boris", "Olga"];

const numberedNames: string[] = names.map(
  (name: string, index: number): string => `${index + 1}. ${name}`
);

console.log(numberedNames);
// ["1. Anna", "2. Boris", "3. Olga"]
```

## 2. Изменение всех элементов, кроме элемента с заданным индексом

Лектор ставит задачу: умножить каждый элемент массива на `2`, кроме третьего элемента.

Так как индексация начинается с `0`, третий элемент имеет индекс `2`.

### Пример из лекции

```ts
const arr: number[] = [1, 2, 3, 4, 5];

const newArr: number[] = arr.map(
  (el: number, index: number): number => {
    if (index !== 2) {
      return el * 2;
    }

    return el;
  }
);

console.log(newArr); // [2, 4, 3, 8, 10]
```

Логика callback:

1. Для каждого элемента проверяется `index`.
2. Если индекс не равен `2`, возвращается удвоенное значение.
3. Если индекс равен `2`, возвращается исходный элемент.
4. `map` собирает возвращённые значения в новый массив.

### Дополнения от AI

Простой аналогичный пример — не изменять первый элемент:

```ts
const prices: number[] = [10, 20, 30];

const result: number[] = prices.map(
  (price: number, index: number): number => {
    if (index === 0) {
      return price;
    }

    return price + 5;
  }
);

console.log(result); // [10, 25, 35]
```

## 3. Метод `forEach`

По объяснению лектора, `forEach`, как и `map`, принимает callback-функцию. Метод проходит по элементам массива, но не создаёт новый массив.

### Пример из лекции

```ts
const arr: number[] = [1, 2, 3];

arr.forEach((el: number) => {
  console.log(el);
});
```

В консоль последовательно выводятся:

```text
1
2
3
```

> **В лекции изложено невнятно:** фраза о том, что `forEach` «ничего не создаёт или не меняет», слишком общая. В примере действительно только выполняется `console.log`, но границы возможного использования метода отдельно не объясняются.

### Дополнения от AI

Практическое различие примеров лекции:

- `map` используется, когда из элементов нужно получить **новый массив**;
- `forEach` используется, когда для каждого элемента нужно выполнить действие, а новый массив не требуется.

Простой пример:

```ts
const fruits: string[] = ["apple", "pear", "orange"];

fruits.forEach((fruit: string) => {
  console.log(fruit);
});
```

Пример среднего уровня — подсчёт общей суммы через внешнюю переменную:

```ts
const prices: number[] = [10, 15, 25];
let total: number = 0;

prices.forEach((price: number) => {
  total = total + price;
});

console.log(total); // 50
```

## 4. Метод `filter`

По объяснению лектора, `filter`:

- фильтрует элементы массива по созданному условию;
- работает похоже на `map`, потому что принимает callback;
- возвращает новый массив.

Callback должен вернуть результат проверки условия. В новый массив попадают элементы, для которых условие истинно.

### Пример из лекции: слова длиннее шести символов

```ts
const words: string[] = [
  "hello",
  "afternoon",
  "fun",
  "paranthesis",
  "hammer"
];

const filteredWords: string[] = words.filter(
  (word: string): boolean => word.length > 6
);

console.log(filteredWords);
// ["afternoon", "paranthesis"]
```

### Пример из лекции: чётные числа

```ts
const numbers: number[] = [1, 2, 3, 4];

const evenNumbers: number[] = numbers.filter(
  (num: number): boolean => num % 2 === 0
);

console.log(evenNumbers); // [2, 4]
```

### Дополнения от AI

Простой пример — оставить положительные числа:

```ts
const values: number[] = [-2, 0, 3, 7];

const positive: number[] = values.filter(
  (value: number): boolean => value > 0
);

console.log(positive); // [3, 7]
```

Пример среднего уровня — оставить имена, начинающиеся с `A`:

```ts
const names: string[] = ["Anna", "Boris", "Alice", "Olga"];

const namesWithA: string[] = names.filter(
  (name: string): boolean => name.startsWith("A")
);

console.log(namesWithA); // ["Anna", "Alice"]
```

## 5. Метод `includes`

Лектор показывает, что `includes` проверяет наличие элемента в массиве и возвращает `true` или `false`.

### Пример из лекции

```ts
const arr: string[] = ["dog", "cat", "bird"];

console.log(arr.includes("dog"));  // true
console.log(arr.includes("fish")); // false
```

У метода показаны два параметра:

- `searchElement` — элемент, который нужно найти;
- `fromIndex` — индекс, начиная с которого нужно искать; отсчёт ведётся от `0`.

```ts
console.log(["a", "b", "c"].includes("a"));    // true
console.log(["a", "b", "c"].includes("b", 1)); // true
console.log(["a", "b", "c"].includes("b", 3)); // false
```

> **В лекции изложено невнятно:** в комментарии говорится о поиске элементов, «соответствующих условию», хотя в показанном коде callback или отдельное условие не используются — передаётся конкретное искомое значение.

### Дополнения от AI

В рамках показанного примера удобнее формулировать так: `includes` проверяет, есть ли в массиве указанное значение.

Простой пример:

```ts
const roles: string[] = ["admin", "editor", "viewer"];

console.log(roles.includes("editor")); // true
```

Пример среднего уровня с начальным индексом:

```ts
const statuses: string[] = ["new", "done", "new"];

console.log(statuses.includes("new", 1)); // true
console.log(statuses.includes("done", 2)); // false
```

## 6. Метод `reduce`

Лектор представляет общую форму метода:

```ts
const res = arr.reduce(callbackFunction, initialValue);
```

По материалу лекции, `reduce` используется, чтобы «свернуть» массив в одно значение. Результатом может быть число, строка, другой массив и так далее.

Лектор выделяет два аргумента метода:

1. callback-функция;
2. начальное значение `initialValue`.

Метод проходит по элементам массива и последовательно передаёт результат предыдущего вычисления в следующий вызов callback. В конце возвращается одно итоговое значение.

### Пример из лекции: сумма элементов

```ts
const arr: number[] = [1, 2, 3, 4];

const sum: number = arr.reduce(
  (accumulator: number, currentValue: number): number => {
    return accumulator + currentValue;
  }
);

console.log(sum); // 10
```

### `accumulator`

По объяснению лектора:

- это первый аргумент callback;
- его также часто называют `acc`;
- он собирает результаты вычислений;
- если начальное значение не передано, в начале он равен первому элементу массива.

### `currentValue`

По объяснению лектора:

- это второй аргумент callback;
- его также называют `value` или `item`;
- он содержит текущее значение элемента массива;
- его значение меняется при каждой итерации.

### Начальное значение

Лектор добавляет к вызову `reduce` начальное значение `100`:

```ts
const arr: number[] = [1, 2, 3, 4];

const sum: number = arr.reduce(
  (accumulator: number, currentValue: number): number => {
    return accumulator + currentValue;
  },
  100
);

console.log(sum); // 110
```

После замены начального значения на `0` результат снова равен `10`:

```ts
const sum: number = arr.reduce(
  (accumulator: number, currentValue: number): number => {
    return accumulator + currentValue;
  },
  0
);
```

> **В лекции изложено неполно:** показано поведение `accumulator` без начального значения и с ним, но последовательность значений по каждой итерации явно не расписана.

### Дополнения от AI

Для массива `[1, 2, 3, 4]` и начального значения `0` вычисления можно представить так:

| Итерация | `accumulator` до сложения | `currentValue` | Новый результат |
|---:|---:|---:|---:|
| 1 | 0 | 1 | 1 |
| 2 | 1 | 2 | 3 |
| 3 | 3 | 3 | 6 |
| 4 | 6 | 4 | 10 |

Простой пример — произведение чисел:

```ts
const numbers: number[] = [2, 3, 4];

const product: number = numbers.reduce(
  (acc: number, item: number): number => acc * item,
  1
);

console.log(product); // 24
```

Пример среднего уровня — собрать одну строку:

```ts
const words: string[] = ["TypeScript", "is", "useful"];

const sentence: string = words.reduce(
  (acc: string, word: string): string => `${acc} ${word}`,
  ""
);

console.log(sentence); // " TypeScript is useful"
```

## 7. Сравнение рассмотренных методов

| Метод | Принимает callback | Что возвращает в примерах лекции | Основное назначение в лекции |
|---|---:|---|---|
| `map` | Да | Новый массив | Преобразовать каждый элемент |
| `forEach` | Да | Новый массив не создаётся | Выполнить действие для каждого элемента |
| `filter` | Да | Новый отфильтрованный массив | Оставить элементы по условию |
| `includes` | Нет | `true` или `false` | Проверить наличие значения |
| `reduce` | Да | Одно итоговое значение | Последовательно объединить результаты |

### Дополнения от AI

Короткая памятка выбора:

```ts
const numbers: number[] = [1, 2, 3, 4];

numbers.map((n: number) => n * 2);          // [2, 4, 6, 8]
numbers.forEach((n: number) => console.log(n));
numbers.filter((n: number) => n % 2 === 0); // [2, 4]
numbers.includes(3);                         // true
numbers.reduce((acc: number, n: number) => acc + n, 0); // 10
```
