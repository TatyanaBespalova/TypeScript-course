## 1. Обработка ошибок: `try`, `catch`, `finally`

На лекции был показан блок обработки ошибок:

```ts
try {
  // код, в котором может произойти ошибка
} catch {
  // код, который выполняется при ошибке
} finally {
  // код, который выполняется после try/catch
}
```

### Роли блоков

- `try` содержит код, который требуется выполнить;
- `catch` срабатывает, если внутри `try` возникла ошибка;
- `finally` выполняется после завершения `try` и `catch`.

### Простой пример из лекции

```ts
try {
  const text: string = "Hello World! ";
  const i: number = -1;

  console.log(text.repeat(i));
} catch {
  console.log("Oops, an error occurred");
} finally {
  console.log("That's all, folks!");
}
```

В примере метод `repeat()` получает отрицательное количество повторений. Возникает ошибка, поэтому управление переходит в `catch`. После этого выполняется `finally`.

Результат, показанный на занятии:

```text
Oops, an error occurred
That's all, folks!
```

### Что произойдёт без ошибки

Если код внутри `try` выполнится успешно, блок `catch` будет пропущен, но `finally` всё равно выполнится.

```ts
try {
  const text: string = "Hello ";
  const i: number = 3;

  console.log(text.repeat(i));
} catch {
  console.log("Oops, an error occurred");
} finally {
  console.log("That's all, folks!");
}
```

Результат:

```text
Hello Hello Hello
That's all, folks!
```

> **В лекции изложено невнятно:** при последовательном комментировании `catch` и `finally` на экране появлялась синтаксическая ошибка. Отдельного правила о допустимых сочетаниях блоков сформулировано не было.

### Дополнения от AI

После `try` должен находиться хотя бы один из блоков: `catch` или `finally`. Можно использовать `try` вместе с `catch`, вместе с `finally` или со всеми тремя блоками. Один блок `try` без продолжения недопустим.

## 2. Создание ошибки с помощью `throw`

На лекции ошибка создавалась вручную с помощью `throw`.

### Пример проверки возраста

```ts
try {
  const age: number = 18;

  if (age < 21) {
    throw "Too young!";
  }

  console.log(`Hello, I'm ${age} years old.`);
} catch (error) {
  console.log(`Oops, an error occurred: ${error}`);
}
```

Поскольку `18 < 21`, выполняется:

```ts
throw "Too young!";
```

Обычное выполнение блока `try` прекращается. Значение после `throw` попадает в параметр `error` блока `catch`.

Результат:

```text
Oops, an error occurred: Too young!
```

### Пример без выбрасывания ошибки

```ts
try {
  const age: number = 25;

  if (age < 21) {
    throw "Too young!";
  }

  console.log(`Hello, I'm ${age} years old.`);
} catch (error) {
  console.log(`Oops, an error occurred: ${error}`);
}
```

Условие `25 < 21` ложно, поэтому `throw` пропускается и выполняется следующий `console.log()`.

### Дополнения от AI

Полезно читать `throw` как «немедленно прекратить нормальное выполнение и передать управление обработчику ошибки». В пределах показанного примера значением ошибки является строка `"Too young!"`.

## 3. Union type — объединение типов

Union type позволяет указать несколько допустимых типов для одной переменной. Типы перечисляются через вертикальную черту `|`.

### Простой пример из лекции

```ts
let value: string | number;

value = "hi";
value = 3;
```

Переменная может содержать строку или число.

Присвоение значения другого типа вызовет ошибку TypeScript:

```ts
value = true;
```

### Несколько допустимых типов

```ts
let value: string | number | boolean;

value = "hi";
value = 3;
value = true;
```

### `null` и `undefined` в объединении

На экране были показаны записи:

```ts
let price: number | null;
let amount: number | undefined;
```

Такая запись явно сообщает, что кроме числа переменная может содержать `null` или `undefined`.

### Пример среднего уровня из лекции: калькулятор

```ts
const operator: string = "+";
const a: number = 10;
const b: number = 5;
let result: number;

if (operator === "+") {
  result = a + b;
} else if (operator === "-") {
  result = a - b;
} else {
  result = 0;
}

console.log(result); // 15
```

Этот пример использовался при переходе от обычной типизации к ситуации, когда значение может иметь несколько вариантов.

### Дополнения от AI

Символ `|` здесь означает «или»: `string | number` читается как «строка или число». Он не создаёт два значения одновременно — в конкретный момент в переменной находится одно значение одного из разрешённых типов.

## 4. Сужение union type с помощью `typeof`

Если переменная допускает несколько типов, перед использованием специфичного метода нужно определить текущий тип значения.

### Пример из лекции

```ts
let id: string | number;

if (typeof id === "string") {
  id.toLowerCase();
} else {
  // здесь TypeScript рассматривает id как number
}
```

Внутри ветки

```ts
if (typeof id === "string")
```

TypeScript разрешает строковые методы, потому что значение проверено как строка.

### Пример среднего уровня

```ts
let value: string | number = "HELLO";

if (typeof value === "string") {
  console.log(value.toLowerCase());
} else {
  console.log(value + 10);
}
```

> **В лекции изложено невнятно:** пример с переменной `id` показывал сам принцип проверки `typeof`, но обе ветки не были развиты в полностью законченный практический пример.

### Дополнения от AI

После проверки TypeScript временно «сужает» объединение. В первой ветке `value` — это `string`, во второй — оставшийся вариант `number`. Поэтому в каждой ветке доступны операции соответствующего типа.

## 5. Union type и массивы: две разные записи

На лекции сравнивались две похожие, но разные конструкции.

### Весь массив имеет один тип элементов

```ts
const data: number[] | string[] = ["1", "2", "3"];
```

Запись означает: `data` — либо массив чисел, либо массив строк.

Допустимые варианты:

```ts
const first: number[] | string[] = [1, 2, 3];
const second: number[] | string[] = ["1", "2", "3"];
```

### В одном массиве разрешены разные типы элементов

```ts
const data: (number | string)[] = ["1", 2, "3"];
```

Скобки показывают, что объединение относится к типу каждого элемента.

### Сравнение

| Запись | Что разрешено |
| --- | --- |
| `number[] | string[]` | целиком числовой либо целиком строковый массив |
| `(number | string)[]` | числа и строки внутри одного массива |

### Пример среднего уровня из лекции

На экране также рассматривался массив, в котором TypeScript выводит типы элементов из самих значений:

```ts
const values = ["hello", 10, true, undefined, ["red", "blue", "world"]];
```

### Дополнения от AI

Чтобы не перепутать записи, сначала определите, к чему относится слово «или»:

- «массив чисел **или** массив строк» → `number[] | string[]`;
- «массив элементов, каждый из которых число **или** строка» → `(number | string)[]`.

## 6. Tuple — кортеж

Tuple — массив с заранее заданными позициями и типом каждой позиции.

### Простой пример из лекции

```ts
let user: [string, number] = ["hi", 1];
```

Здесь:

- элемент с индексом `0` должен быть строкой;
- элемент с индексом `1` должен быть числом.

### Изменение элементов

```ts
user[0] = "hello";
user[1] = 2;
```

Тип позиции должен сохраняться.

### Пример среднего уровня из лекции

Кортеж применялся как набор из трёх чисел, например для RGB-значения:

```ts
let rgb: [number, number, number] = [255, 255, 255];
```

Лектор сопоставил три позиции с тремя координатами или составляющими цвета.

### Проверка массива

На примере кортежа также показывались:

```ts
console.log(typeof user);        // "object"
console.log(Array.isArray(user)); // true
```

То есть во время выполнения кортеж остаётся массивом.

> **В лекции изложено невнятно:** в примере с tuple использовался `push()`, но не было сформулировано, как это соотносится с фиксированным количеством позиций.

### Дополнения от AI

Tuple задаёт известную структуру позиций на уровне TypeScript. Однако некоторые обычные методы массива, включая `push()`, могут создавать поведение, которое выглядит неожиданно для фиксированной структуры. Для начальных заданий безопаснее изменять только объявленные позиции и не увеличивать tuple через `push()`.

## 7. Для чего нужны циклы

Лектор объяснил цикл как конструкцию, позволяющую многократно выполнять одно действие. Без цикла одинаковые команды пришлось бы писать повторно.

Например, вместо нескольких строк:

```ts
console.log("Hello");
console.log("Hello");
console.log("Hello");
```

можно использовать цикл.

### Дополнения от AI

Цикл полезен, когда:

- действие повторяется несколько раз;
- нужно пройти по строке или массиву;
- количество элементов заранее может быть разным.

Это пояснение суммирует назначение примеров лекции и не является отдельной формулировкой лектора.

## 8. Цикл `for`: синтаксис и порядок работы

Основная форма цикла:

```ts
for (let i: number = 0; i < 5; i++) {
  console.log(i);
}
```

В круглых скобках находятся три компонента:

1. `let i: number = 0` — создание счётчика и начальное значение;
2. `i < 5` — условие продолжения цикла;
3. `i++` — изменение счётчика после итерации.

Между компонентами ставятся точки с запятой.

### Как выполняется цикл

1. Создаётся `i` со значением `0`.
2. Проверяется условие `i < 5`.
3. Если условие истинно, выполняется тело цикла.
4. Выполняется `i++`.
5. Условие проверяется снова.
6. Когда условие становится ложным, цикл завершается.

Результат:

```text
0
1
2
3
4
```

### Если условие сразу ложно

Тело цикла не выполнится ни одного раза:

```ts
for (let i: number = 5; i < 5; i++) {
  console.log(i);
}
```

### Пример среднего уровня из лекции

```ts
console.log("Before loop");

for (let i: number = 3; i < 6; i++) {
  console.log("Hello");
  console.log(i);
}

console.log("After loop");
```

Команды до цикла выполняются один раз, тело — для каждой итерации, команда после цикла — один раз после завершения.

### `i++` и `i = i + 1`

В коде лекции увеличение счётчика записывалось как `i++`. В комментариях оно также объяснялось как изменение значения на единицу.

```ts
i++;
```

В контексте показанного цикла это соответствует:

```ts
i = i + 1;
```

### Дополнения от AI

Условие цикла — это не условие входа только один раз. Оно проверяется перед каждой новой итерацией. Как только результат становится `false`, выполнение переходит к первой команде после цикла.

## 9. Границы цикла: `<` и `<=`

На лекции значение счётчика сопоставлялось с условием цикла.

```ts
for (let i: number = 0; i < 5; i++) {
  console.log(i);
}
```

Выводятся значения от `0` до `4`. Число `5` не выводится, потому что проверка `5 < 5` ложна.

Если написать `i <= 5`, значение `5` тоже войдёт в цикл:

```ts
for (let i: number = 0; i <= 5; i++) {
  console.log(i);
}
```

### Пример с массивом

```ts
const numbers: number[] = [1, 2, 3, 4, 5];

for (let i: number = 0; i < numbers.length; i++) {
  console.log(numbers[i]);
}
```

Для индексов массива использовалось условие `i < numbers.length`.

### Дополнения от AI

Если длина массива равна `5`, допустимые индексы — `0`, `1`, `2`, `3`, `4`. Поэтому для обхода массива обычно используется `< array.length`, а не `<= array.length`.

## 10. Обход строки и подсчёт символов

На лекции цикл применялся для прохода по строке по индексам.

### Задача: посчитать букву `e`

```ts
const str: string = "Hello, my name is Peter and I am a TypeScript student";
let count: number = 0;

for (let i: number = 0; i < str.length; i++) {
  if (str[i] === "e") {
    count++;
  }
}

console.log(count);
```

Логика:

1. `i` последовательно принимает индексы строки;
2. `str[i]` возвращает символ по текущему индексу;
3. символ сравнивается с `"e"`;
4. при совпадении счётчик увеличивается.

### Простой вариант

```ts
const text: string = "tree";
let count: number = 0;

for (let i: number = 0; i < text.length; i++) {
  if (text[i] === "e") {
    count++;
  }
}

console.log(count); // 2
```

### Дополнения от AI

Здесь используются два разных счётчика по смыслу:

- `i` показывает текущую позицию в строке;
- `count` хранит количество найденных совпадений.

Они не заменяют друг друга.

## 11. Обход массива и суммирование элементов

На лекции задача суммирования массива была решена через цикл.

```ts
const arr: number[] = [1, 2, 3, 4, 5];
let sum: number = 0;

for (let i: number = 0; i < arr.length; i++) {
  sum += arr[i];
}

console.log(sum); // 15
```

### Как меняется `sum`

| Итерация | `arr[i]` | Новое значение `sum` |
| --- | ---: | ---: |
| начало | — | 0 |
| `i = 0` | 1 | 1 |
| `i = 1` | 2 | 3 |
| `i = 2` | 3 | 6 |
| `i = 3` | 4 | 10 |
| `i = 4` | 5 | 15 |

### Полная и сокращённая запись

В комментариях к примеру были сопоставлены:

```ts
sum = sum + arr[i];
```

и сокращённый вариант:

```ts
sum += arr[i];
```

### Дополнения от AI

Начальное значение `sum` равно `0`, потому что это нейтральное значение для сложения: прибавление первого элемента к нулю не изменяет сам элемент.

## 12. Вложенные циклы

Вложенный цикл — цикл внутри другого цикла.

### Простой пример из лекции

```ts
for (let i: number = 0; i < 5; i++) {
  console.log("i:", i);

  for (let j: number = 0; j < 3; j++) {
    console.log("j:", j);
  }
}
```

Для каждого значения `i` внутренний цикл полностью проходит значения `j`.

### Подсчёт элементов двухмерного массива

```ts
const arr: number[][] = [
  [1, 2],
  [3, 4, 5],
  [6, 7, 8],
];

let count: number = 0;

for (let i: number = 0; i < arr.length; i++) {
  const element = arr[i];

  for (let j: number = 0; j < element.length; j++) {
    count += element[j];
  }
}

console.log(count);
```

В показанном коде внешний цикл выбирает внутренний массив, а внутренний цикл проходит его элементы.

> **В лекции изложено невнятно:** переменная называлась `count`, хотя в неё добавлялись сами значения элементов. Поэтому пример фактически вычислял сумму элементов, а название могло создать впечатление, что подсчитывается их количество.

### Дополнения от AI

Если требуется именно количество элементов, увеличение выглядело бы как `count++`. Если используется `count += element[j]`, получается сумма значений. Я не меняю код лекции, а только разделяю два разных смысла.

## 13. Построение фигуры из символов

Вложенные циклы использовались для построения треугольника из звёздочек.

Ожидаемый рисунок:

```text
*
**
***
****
*****
```

### Пример из лекции

```ts
let str: string = "";

for (let i: number = 0; i < 5; i++) {
  for (let j: number = 0; j < i + 1; j++) {
    str += "*";
  }

  str += "\n";
}

console.log(str);
```

Внешний цикл отвечает за строки. Внутренний добавляет нужное количество звёздочек. После каждой строки добавляется перенос `"\n"`.

### Дополнения от AI

При `i = 0` условие внутреннего цикла `j < i + 1` даёт одну звёздочку. При `i = 1` — две и так далее. Выражение `i + 1` нужно потому, что счётчик начинается с нуля, а первая строка должна содержать один символ.

## 14. `break` и `continue`

На лекции были сформулированы два действия:

- `break` полностью прекращает выполнение цикла;
- `continue` прекращает только текущую итерацию и переходит к следующей.

### `break`

```ts
for (let i: number = 0; i < 5; i++) {
  if (i === 3) {
    break;
  }

  console.log(i);
}

console.log("End");
```

Результат:

```text
0
1
2
End
```

Когда `i` становится равным `3`, цикл завершается целиком.

### `continue`

```ts
for (let i: number = 0; i < 5; i++) {
  if (i === 3) {
    continue;
  }

  console.log(i);
}

console.log("End");
```

Результат:

```text
0
1
2
4
End
```

Значение `3` пропускается, но цикл продолжает работу.

### Пример среднего уровня из лекции: пропуск отрицательных чисел

```ts
const numbers: number[] = [10, 5, -1, 3, -8, 12];

for (let i: number = 0; i < numbers.length; i++) {
  if (numbers[i] < 0) {
    continue;
  }

  console.log(numbers[i]);
}

console.log("End");
```

Отрицательные элементы не выводятся.

### Дополнения от AI

Удобная проверка:

- нужно закончить весь цикл → `break`;
- нужно пропустить только один неподходящий элемент → `continue`.

## 15. Счётчик, объявленный до цикла

На лекции отдельно показано: если значение счётчика понадобится после завершения цикла, переменную можно объявить заранее.

```ts
let i: number = 0;

for (; i < 5; i++) {
  console.log(i);
}

console.log(i);
```

Инициализация отсутствует в первой части круглых скобок, потому что `i` уже создана до `for`.

### Дополнения от AI

Если написать `let i` непосредственно внутри `for`, переменная доступна только внутри цикла и его заголовка. Вынесение объявления наружу расширяет область, где к ней можно обратиться.

## 16. Цикл `while`

В `while` сначала проверяется условие, затем выполняется тело цикла.

### Простой пример из лекции

```ts
let index: number = 0;

while (index < 3) {
  console.log(index);
  index++;
}
```

Результат:

```text
0
1
2
```

### Пример среднего уровня из лекции: массив строк

```ts
const fruits: string[] = ["apple", "pears", "plums", "grape"];
let i: number = 0;

while (i < fruits.length) {
  console.log(fruits[i]);
  i++;
}
```

Внутри `while` необходимо изменять переменную, участвующую в условии. В показанном примере выполняется `i++`.

> **В лекции изложено неполно:** различие в выборе между `for` и `while` не было оформлено как отдельное правило; были показаны их рабочие примеры.

### Дополнения от AI

По примерам лекции `for` удобно использовать, когда создание счётчика, условие и изменение логично собрать в одной строке. `while` оставляет в заголовке только условие, а начальное значение и изменение записываются отдельно.

## 17. Почему два одинаковых массива не равны через `===`

На лекции сравнивались два отдельных массива с одинаковыми элементами:

```ts
let arrA: number[] = [1, 2, 3];
let arrB: number[] = [1, 2, 3];

console.log(arrA === arrB); // false
```

Лектор объяснил это тем, что сравнивается не содержимое массивов. Две переменные относятся к двум разным массивам.

### Одна ссылка на массив

```ts
let arrA: number[] = [1, 2, 3];
let arrB: number[] = arrA;

console.log(arrA === arrB); // true
```

В этом случае новый массив не создаётся. Обе переменные связаны с одним существующим массивом.

### Изменение через вторую переменную

```ts
let arrA: number[] = [1, 2, 3];
let arrB: number[] = arrA;

arrB.push(4);

console.log(arrA); // [1, 2, 3, 4]
console.log(arrB); // [1, 2, 3, 4]
```

### Дополнения от AI

Представьте один массив как одну коробку, а `arrA` и `arrB` — как две подписи, указывающие на неё. Изменение коробки видно через обе подписи.

## 18. Сравнение содержимого массивов

На лекции был показан ручной алгоритм:

1. сравнить длины;
2. если длины равны, пройти по элементам;
3. сравнить элементы с одинаковыми индексами;
4. при первом несовпадении установить результат `false` и выйти через `break`.

```ts
let arrA: number[] = [1, 2, 3];
let arrB: number[] = [1, 2, 3];
let result: boolean = false;

if (arrA.length === arrB.length) {
  result = true;

  for (let i: number = 0; i < arrA.length; i++) {
    if (arrA[i] !== arrB[i]) {
      result = false;
      break;
    }
  }
}

console.log(result);
```

### Преобразование массивов в строки

Также рассматривалось сравнение результатов `toString()`:

```ts
const strA: string = arrA.toString();
const strB: string = arrB.toString();

console.log(strA === strB);
```

Лектор отметил, что здесь фактически сравниваются уже строки, а не массивы.

### `JSON.stringify()`

На экране был показан ещё один вариант:

```ts
console.log(JSON.stringify(arrA) === JSON.stringify(arrB));
```

`JSON.stringify()` преобразует значение в строковое представление JSON.

> **В лекции изложено неполно:** ограничения сравнения массивов через `toString()` или `JSON.stringify()` подробно не разбирались.

### Дополнения от AI

Для материала этой лекции наиболее прозрачным является ручной алгоритм с проверкой длины и элементов. Он прямо показывает, что именно сравнивается. Строковые варианты следует воспринимать только как продемонстрированные способы, без переноса на любые сложные структуры.

## 19. Объединение массивов: `concat()` и spread operator

### `concat()`

```ts
let arr1: number[] = [1, 2, 3];
let arr2: number[] = [4, 5, 6];
let arr3: number[] = arr1.concat(arr2);

console.log(arr3); // [1, 2, 3, 4, 5, 6]
```

### Spread operator

На лекции тот же результат получали через `...`:

```ts
let arr1: number[] = [1, 2, 3];
let arr2: number[] = [4, 5, 6];
let arr3: number[] = [...arr1, ...arr2];

console.log(arr3); // [1, 2, 3, 4, 5, 6]
```

В комментарии лектора spread operator описан как «разворачивание» массива.

### Дополнения от AI

В выражении `[...arr1, ...arr2]` элементы первого и второго массивов помещаются в новый массив по порядку. Сам символ `...` не означает многоточие текста — это оператор с отдельным назначением.

## 20. Преобразование строки в массив: `split()`

```ts
const str: string = "hello";

console.log(str.split(""));
// ["h", "e", "l", "l", "o"]
```

Пустая строка-разделитель разбивает исходную строку на отдельные символы.

Разделитель `","` определяет места разрезания строки и сам в элементы результата не входит.

## 21. Создание копии массива

### Копия одномерного массива через spread

```ts
let original: number[] = [1, 2, 3];
let copy: number[] = [...original];

original.push(4);

console.log(original); // [1, 2, 3, 4]
console.log(copy);     // [1, 2, 3]
```

В отличие от `copy = original`, spread создаёт новый внешний массив.

### Поверхностная копия вложенного массива

На лекции было показано, что spread недостаточен для независимого копирования вложенных массивов:

```ts
let original: (number | number[])[] = [1, 2, 3, [4, 5]];
let copy: (number | number[])[] = [...original];
```

Добавление нового элемента во внешний `original` не изменяет `copy`:

```ts
original.push(4);
```

Но изменение вложенного массива может быть видно в обеих переменных, потому что вложенный массив остаётся общим.

На экране перед работой с вложенным значением применялась проверка:

```ts
if (Array.isArray(original[3])) {
  original[3][0] = -10;
}
```

### Глубокая копия через `structuredClone()`

```ts
let original: (number | number[])[] = [1, 2, 3, [4, 5]];
let copy: (number | number[])[] = structuredClone(original);
```

После глубокого копирования вложенный массив копии отделён от вложенного массива оригинала.

На занятии также была показана более старая запись:

```ts
JSON.parse(JSON.stringify(original));
```

Лектор назвал `structuredClone()` наиболее современным способом среди рассмотренных.

> **В лекции изложено неполно:** ограничения `structuredClone()` и варианта через JSON не рассматривались.

### Дополнения от AI

В рамках показанного примера достаточно различать:

- `[...original]` — новый внешний массив, но вложенные массивы остаются общими;
- `structuredClone(original)` — создаётся независимая копия вложенной структуры.

Я не распространяю это правило на неподтверждённые лекцией сложные типы данных.
