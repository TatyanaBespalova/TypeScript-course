# Элементарные задания на if / else в TypeScript

if (что проверить//  условие) {
  что выполнить//  код, который нжно выполнить
}

if → (условие) и {действия}
else if → (условие) и {действия}
else → только {действия}


## Задание 1. Положительное или отрицательное число

Дано число:

```ts
const number: number = 7;
```

Если число больше `0`, выведи:

```text
Число положительное
```

Иначе выведи:

```text
Число отрицательное или равно нулю
```

---

## Задание 2. Чётное или нечётное число

Дано число:

```ts
const number: number = 8;
```

Если число чётное, выведи:

```text
Число чётное
```

Иначе выведи:

```text
Число нечётное
```

Подсказка:

```ts
number % 2
```

---

## Задание 3. Совершеннолетний пользователь

Дан возраст пользователя:

```ts
const age: number = 20;
```

Если пользователю исполнилось `18` лет, выведи:

```text
Доступ разрешён
```

Иначе выведи:

```text
Доступ запрещён
```

---

## Задание 4. Проверка пароля

Дан пароль:

```ts
const password: string = "typescript";
```

Если пароль равен `"typescript"`, выведи:

```text
Пароль правильный
```

Иначе выведи:

```text
Пароль неправильный
```

---

## Задание 5. Сравнение двух чисел

Даны два числа:

```ts
const firstNumber: number = 12;
const secondNumber: number = 7;
```

Если первое число больше второго, выведи:

```text
Первое число больше
```

Иначе выведи:

```text
Второе число больше или числа равны
```

---

Дана температура:

Если температура выше `25`, выведи:


```ts
const quantity: number = 3;
```

Если количество больше `0`, выведи:


## Задание 8. Результат теста

Дан результат теста:

```ts
const testPassed: boolean = true;
```

Если значение `testPassed` равно `true`, выведи:

```text
Test passed
```

Иначе выведи:

```text
Test failed
```

---

## Задание 9. Бесплатная доставка

Дана сумма заказа:

```ts
const orderTotal: number = 75;
```

Если сумма заказа составляет не менее `50`, выведи:

```text
Free delivery
```

Иначе выведи:

```text
Delivery fee applies
```

---

## Задание 10. Проверка логина и пароля

Даны логин и пароль:

```ts
const login: string = "admin";
const password: string = "1234";
```

Если логин равен `"admin"` и пароль равен `"1234"`, выведи:

```text
Вход выполнен
```

Иначе выведи:

```text
Неверный логин или пароль
```

Для проверки двух условий используй оператор `&&`.
